# 탐사 인벤토리·기지·카드 성장: 작업 순서와 설계 인터뷰

상태: 첫 전투/저장 적용 완료(13장). 최신 기획 결정은 14장, 손패/리롤과 카드 표현의 최신 적용은 15장에 기록했다. 안정 카드 사망 보존과 불안정 카드 소멸을 우선 채택하여, 이전 장의 침식 확률 소멸 구상은 보류한다. 정비 턴 소진 시 다음 지역 맵 선택으로 이동하고 정비 카드 사용에도 리스크를 적용한다. 과거 인터뷰 기록·제안과 현재 구현을 구분하며, 14장은 기획 정리이며 15장은 후속 게임 변경을 기록한다.

## 1. 요청받은 방향

- 플레이어 HUD는 좌측 하단, 배낭 그림 버튼은 우측 하단에 둔다. 턴 종료와 리롤은 손패 가까이에 둔다.
- 배낭 버튼은 좌측 탐사 인벤토리 오버레이를 연다. 탐사 중 소지한 카드·아이템을 확인한다. **배낭의 모든 카드는 즉시 전투 덱에 편입**된다. 획득 카드가 손패/뽑기/버림 중 어디로 들어갈지는 미정이다.
- 기지 창고는 탐사 인벤토리와 다른 저장 공간이다. 기본 60칸이며 퀘스트·강화로 확장한다.
- 창고를 열면 탐사 인벤토리도 함께 표시한다. 드래그로 양방향 이동, 인벤토리의 모두 창고로 이동, 창고 정렬을 제공한다.
- 기지에는 건설·상점/상인 퀘스트·창고·강화 기능이 있다. 건설은 테스트 단계에서 재료를 요구하지 않는다. 카드 합성·능력 강화의 비용은 별도 결정 사항이다.
- 상점은 카드·아이템 구매와 판매, 상인 퀘스트 수락·완료를 제공한다. 탐사 중 상점도 같은 화면 구성을 재사용할 수 있다.
- 확정된 6등급: **노말 → 레어 → 에픽 → 유니크 → 레전드리 → 미스틱**. 최초 5등급의 별 모양에 에픽을 어떻게 구분해 넣을지는 추가 결정한다. 이번 답변의 커먼은 노말과 같은 최저 등급을 가리키는 표현으로 우선 이해하며 별도 일곱 번째 등급을 추가하지 않는다.
- 같은 등급 카드 3장으로 상위 등급 1장을 만든다. **승급은 100% 성공**한다. 고유 효과를 유지하며, 매 승급에 랜덤 옵션 1개를 추가한다. 리스크 1개를 선택하면 옵션을 1개 더 얻는다. 일반 승급에서 기존 옵션의 등급·수치는 유지하고 새 옵션만 추첨한다. 미스틱 3장 재합성의 일반 강화는 기본 5개를 각 승급 단계의 확률표로 재추첨한다. 선택 강화는 리스크 r개(최대 4개)를 정해 총 옵션 5+r개를 구성하고, 추가 슬롯은 미스틱부터 역순의 승급 단계 확률표를 쓴다. 미스틱 재합성은 기존 옵션·리스크를 교체해 선택한 수량으로 재구성한다. 리스크 슬롯은 에픽 1칸부터 미스틱 4칸까지 늘며 실제 리스크를 넣지 않고 비워둘 수 있다.
- 카드 잡기 상태에서 유효 대상을 강조하고 주변을 어둡게 한다. 대상 위에서 예상 결과를 확인하고 릴리즈로 사용한다. 여기서 ‘스크롤’은 카드를 대상으로 끌어가는 동작으로 해석한다.
- 공격 카드는 적, 방어 카드는 플레이어 HUD, 전술 카드는 배낭 UI에 놓는다. 회복·혼합 효과 카드의 주 대상은 아래에서 추가 정의한다.
- 탐사 획득 카드에는 **불안정 표식**을 붙여 귀환 전 사망 시 확정 소멸하게 한다. 사용으로 쌓이는 확률 수치는 별도로 분리하기로 했으며, 이름은 **침식**을 추천 가칭으로 쓴다. 귀환하면 불안정 표식은 제거하고 침식은 일부 감소하며, 기지에서 침식을 추가로 낮춘다. 등급별 누적량은 미정이다.
- 옵션은 카드와 별개의 등급을 가지며 카드 등급 이하의 옵션만 얻는다. 일반 옵션은 수치 효과, 고유 옵션은 철갑탄·해제·무력화 등의 중복 제한 효과다.
- 리스크는 에너지 비용 증가·체력 소모 및 턴 디버프다. 제시된 디버프는 취약·스트레스·승화·저주·파멸의식이며 해당 카드 사용 시 발동해 정해진 턴 동안 지속한다. 모든 본효과보다 리스크를 먼저 적용한다. 강도·턴 수 수치는 미정이며 중첩 규칙은 6장 확정 내용을 따른다.

## 2. 현재 구현에서 먼저 해결할 제약

현재 `game.js`의 저장은 카드 종류별 해금 목록이다. 동일 카드 여러 장, 각 카드의 옵션·등급·안정 상태를 저장하지 못한다. 전투 덱도 기본 덱과 해금 카드를 구역별로 재생성한다. 새로고침하면 탐사 중 진행 상태는 유지되지 않는다.

등급은 순번 대신 명시적인 식별자로 저장해 에픽 삽입이 기존 유니크·레전드리의 의미를 바꾸지 않게 한다. 따라서 같은 카드 3장을 합성하기 전에 ‘종류의 정의’와 ‘소유한 한 장’을 분리해야 한다. 한 장의 카드가 손패·뽑기 더미·버림 더미로 움직여도 같은 소유 개체다. 배낭에 들어 있는 카드가 전투 덱에 참조된다고 소유 수량을 두 번 세면 안 된다.

현재 철갑탄은 장갑과 쉴드를 모두 우회한다. 새 규칙의 철갑탄은 **장갑 무시**, 해제는 **쉴드 전량 파괴**이므로 효과와 계산을 분리해야 한다. 현재 회복 카드도 전술 분류이므로, 드롭 영역을 결정할 때 재분류 또는 명시적인 주 대상이 필요하다.

T03~T04에서는 인벤토리 오버레이 중 전투 결과 처리를 대기시킬지, 전투 중 소지품 이동·아이템 사용을 허용할지도 결정한다. 초기 추천안은 조회 중 적 행동 결과 처리를 대기시키고, 손패의 사용 드래그와 소지품의 위치 이동을 다른 모드로 구분하는 것이다. 전술 카드를 배낭 버튼에 놓는 동작은 카드 사용이며, 버튼을 눌러 인벤토리를 여는 동작과 구별한다.

처음부터 모든 시설을 구현하기보다, T01~T04에서 ‘소유한 물건이 안전하게 이동하고, 카드 결과를 정확히 예측하는’ 작은 완성 구간을 먼저 만든다. 시설 화면의 외형 설계는 병행할 수 있지만 거래·합성 결과는 공통 소유 모델을 사용한다.

## 4. 데이터와 저장의 경계

| 구분 | 보관하는 내용 |
| --- | --- |
| 카드 정의 | 이름, 고유 효과, 주 대상, 기본 비용, 허용 옵션 풀 |
| 소유 카드 | 고유 ID, 정의 ID, 카드 등급, 옵션별 실제 등급·수치·중복 제한·추첨 단계·기본/리스크 보너스 슬롯 구분, 강화 수준, 불안정 표식, 침식 0~100, 등급별 리스크 수용 한도와 실제 채운 리스크, 보너스 옵션과의 연결, 획득 출처 |
| 소유 아이템 | 고유 ID, 종류, 수량, 묶음 규칙, 안정 상태 |
| 기지 | 창고 위치와 용량, 시설, 안정 통화, 강화, 퀘스트 상태 |
| 탐사 | 배낭, 배낭 카드 전체의 ID를 참조하는 전투 덱, 전리품/통화, 진행 상태 |
| 전투 | 손패·뽑기·버림의 카드 ID 참조, 임시 효과의 강도·기간·발동 시점, 에너지, 적 행동 예약, 실행별 명중 결과 |

카드의 불안정 표식과 침식 수치를 별도 보존한다. 최신 사망 규칙은 14장을 따른다: 안정 카드는 보존하고 불안정 카드는 소멸한다. 기존의 침식 수치에 따른 안정 카드 확률 소멸은 보류하며, 데이터 필드가 있다는 이유로 판정하지 않는다.

이동·구매·판매·합성은 ‘기존 물건 제거’와 ‘결과 지급’을 한 번의 상태 변경으로 저장한다. 창고 정렬은 위치만 바꾸며 등급·옵션·불안정 표식·침식을 다시 추첨하지 않는다.

기존 저장에는 과거 중복 획득 장수가 남아 있지 않아 이를 복원할 수 없다. 이관 시 기본 덱 12장과 기존 해금별 1장을 지급하는 방안 등을 명시적으로 결정한다. 이전 CR와 귀환 기록은 보존하고, 추가 지급은 한 번만 수행한다.

배낭의 모든 카드가 즉시 전투 덱을 구성한다. 별도의 장착 덱이나 전리품 전용 카드 덱을 강제하지 않는다. 손패·뽑기·버림 더미는 같은 소유 카드 ID를 참조한다. 획득 직후 어느 더미에 놓는지, 판매·창고 이동·버리기로 덱에서 빠질 때의 참조 정리는 규칙이 필요하다. 추천 출발점은 새 카드를 뽑기 더미에 넣고 섞는 것이며 아직 확정하지 않았다.

배낭 용량, 재료 묶음 수, 카드의 칸 점유는 미정이다. 추천 출발점은 카드 한 장=한 칸, 같은 재료는 정해진 상한까지 묶음이다. ‘모두 창고로 이동’에 카드도 포함하면 전투 덱도 함께 비워진다는 점을 UI에서 알려야 한다. 배낭의 모든 카드가 자동 편입된다는 이유로 획득 즉시 손패에 무료로 뽑아 주는 것으로 해석하지 않는다.

## 5. 불안정 표식과 침식 수치의 분리

> 아래는 이전 인터뷰와 확률 모델 검토 기록이다. 안정 카드의 침식 확률 소멸은 14장의 최신 결정으로 보류했다. 누적/완화 수치와 용도는 재검토 대상이며 현재 확정된 손실 규칙으로 적용하지 않는다.

**사용자 결정:** 탐사 획득품에 붙는 불안정과 사용으로 쌓이는 % 수치를 구분한다. **명칭 추천 가칭:** % 수치를 ‘침식’이라고 부른다. 명칭 자체는 아직 사용자 확정이 아니다.

| 구분 | 불안정 | 침식 — 추천 가칭 |
| --- | --- | --- |
| 성격 | 귀환 전 전리품 표식, 있음/없음 | 사용으로 누적하는 0~100% 수치 |
| 획득/증가 | 탐사에서 새 카드 획득 | 카드 사용 확정당 등급별 증가량을 적용하는 방향 |
| 사망 | 표식이 있으면 수치와 무관하게 확정 소멸 | 표식이 없으면 이 수치가 카드별 소멸 확률 |
| 귀환 | 표식 제거 | 일부 감소 |
| 기지 | 귀환 후 표식 없음 | 추가 안정화로 감소 |

유효 소멸 확률은 **불안정 표식이 있으면 100%, 없으면 침식 %**다. 두 번 판정하거나 두 확률을 더하지 않는다. 예를 들어 ‘불안정 · 침식 12%’인 카드는 현재 사망 시 확정 소멸한다. 침식 12%는 귀환해서 표식이 제거된 뒤 남을 위험을 나타낸다. 안정 카드의 침식이 12%라면 사망 시 소멸 확률은 12%다.

새 탐사 카드도 사용하면 침식이 누적되므로, 이미 확정 소멸인 카드를 써도 귀환 후까지 아무 부담이 없는 구조는 아니다. 일반/고유 랜덤 옵션의 슬롯을 소모하지 않는 상태로 표현하는 안을 추천한다. 배낭과 상세 화면은 ‘불안정: 사망 시 확정 소멸’과 ‘침식: 안정 카드의 사망 소멸 확률’을 혼동하지 않게 구분한다.

| 상황 | 결정 / 추천 / 미정 |
| --- | --- |
| 탐사 카드 획득 | 불안정 표식 부여. 최초 침식값은 아직 미정이며 0% 시작을 추천 |
| 일반적인 카드 사용 | 소유 개체는 유지하고 전투의 버림 더미로 이동 |
| 반복 사용 | 등급별 침식 증가량을 적용. 증가량, 고등급일수록 빠른지 느린지는 미정 |
| 사용 횟수의 단위 | 추천: 유효한 카드 실행 확정 1회당 한 번. 미리보기·취소·사용 불가는 0회. 빗나감은 실행했으므로 1회로 세는 안. 타격·대상·지속 발동은 추가 사용으로 세지 않음 |
| 사망 | 불안정 카드는 확정 소멸, 나머지 소지 카드는 침식 %로 한 번 판정. 창고 물건은 대상이 아님 |
| 정상 귀환 | 불안정 제거와 침식 일부 감소. 감소량, 고정 %p/현재 값의 비율 중 방식은 미정 |
| 기지 안정화 | 침식을 추가 감소. 감소량·비용·시간·최저치·사용 시설은 미정이며 기본 생명주기 작업 T02에 포함 |
| 사망했지만 살아남은 카드 | 침식 유지/감소/초기화와 정비 방식은 미정 |
| 창고 가득 참 | 추천: 귀환 정산과 입고를 분리하고 배낭에 남겨 정리할 수 있게 함 |
| 탐사 중 판매·합성 | 허용 여부, 결과의 불안정 표식·침식 승계, 판매대금 보존 규칙 미정 |

### 침식 누적 방식 비교

추천 출발점은 퍼센트포인트의 단순 누적이다. e₀는 시작 침식, d는 한 번 사용할 때 더하는 수치, n은 확정 사용 횟수다. 불안정 표식 여부와 무관하게 침식 자체를 누적한다.

- 단순 누적: e = min(100%, e₀ + n × d). 예: 매 사용 +2%p이면 10번 사용 후 20%.
- 남은 안정성 기준 누적: e = 1 − (1 − e₀) × (1 − d)ⁿ. 예: 매 사용 2%이면 10번 후 약 18.29%.
- d의 등급별 수치는 아직 정하지 않았다. 위의 2%는 식을 비교하기 위한 예시다.

| 0%에서 카드당 증가량 2%를 가정한 횟수 | 단순 누적 | 남은 안정성 기준 누적 |
| --- | ---: | ---: |
| 5회 | 10% | 약 9.61% |
| 10회 | 20% | 약 18.29% |
| 20회 | 40% | 약 33.24% |

### 플레이에 주는 영향

- 주력 카드를 사용할수록 위험이 쌓여 아껴 쓰게 될 수 있다. 값싼 드로우 카드와 반복 사용 카드도 사용 빈도가 높아 더 빨리 위험해진다. 역할별 실제 사용 빈도를 측정한 뒤 누적량을 정한다.
- 귀환은 신규 카드의 불안정 제거와 침식 일부 감소라는 보상을 주고, 기지 안정화가 다음 출정 준비로 연결된다.
- 새 전리품도 사용하면 침식이 쌓여 귀환 후 남는다. 이전 단일 수치 모델에서 생겼던 ‘100% 전리품만 먼저 쓰면 추가 위험이 없다’는 분석은 이 분리 결정으로 수정한다.
- 카드별 독립 판정이면 사망 시 각각 20%인 안정 카드 5장 중 한 장 이상 잃을 확률은 1−0.8⁵ = 약 67.23%다. 이는 사망을 조건으로 한 확률이며 탐사 전체의 사망 확률과는 다르다.
- 합성/판매/재접속으로 불안정 표식이나 침식이 부당하게 사라지지 않도록 승계·정산을 함께 정의한다. 추천 승계안은 표식은 입력 중 하나라도 있으면 유지, 침식은 재료 중 최댓값을 유지하는 방식이며 미확정이다.
- 현재 기본 덱을 매 구역 재생성하는 구조는 소멸 규칙과 맞지 않는다. 소멸 카드 참조를 제거하고, 출정 덱이 부족해진 경우의 대여 덱·복구 수단은 별도 결정한다.

침식 누적량과 귀환 감소량은 함께 조정한다. 귀환의 고정 감소량이 실제 사용 누적량 이상이면 매번 0%가 되어 기지 안정화가 필요 없어질 수 있다. 반대로 귀환 감소가 지나치게 작으면 주력 카드 사용을 피하거나 매 출정 정비가 강제될 수 있다. 카드당 사용 횟수·사망률·안정화 비용을 기록한 뒤 수치를 고른다.

사망 판정은 카드 ID별 한 번만 수행하고 결과와 덱/배낭 정리를 함께 저장하는 안을 추천한다. 귀환과 기지 안정화도 한 번만 정산해 재접속으로 중복 감소하지 않게 한다.

## 6. 카드 옵션을 나누는 기준

### 효과 처리 인터뷰 — 현재 진행 순서

사용자 요청에 따라 효과 처리를 다른 미정 항목보다 먼저 정한다.

| 단계 | 정할 범위 | 상태 |
| --- | --- | --- |
| A | 일반 수치 옵션 중복·합산, 서로 다른 고유 옵션 공존, 동일 디버프 재적용 | 답변 반영 완료 |
| B | 리스크와 본효과 선후, 회복 횟수, 게임 턴 단위 | 회복1회/공통 턴은 유지. 순서는 E 답변으로 리스크 우선으로 변경 |
| C | 전부 빗나간 공격의 회복과 해제, 행동 대기 1→0 실행 시점 | 답변 반영 완료 |
| D | 승화의 지속 차단, 강도별 독립 기간, 발동 게임 턴부터 기간 감소 | 답변 반영 완료 |
| E·F | 리스크 우선, HP 소모 조건, 독립 회복/드로우/에너지, 무력화 발동, 같은 강도 갱신 | 답변 반영 완료 |
| G | 지속 옵션의 유지/반복, 저주 리롤의 카드 이동, 전투 끝의 지속 효과 | 지속2턴·저주·전투 종료 해제 답변 반영. 쉴드 리필은 추천 검토 |

**A단계 확정:**

- 일반 옵션은 같은 종류도 중복 허용하고 합산 표시한다. 피해 +3과 +5는 화면에 피해 +8로 요약하되, 실제 옵션 두 개의 각각의 등급·수치·추첨 단계는 유지한다. 표시 합산 때문에 옵션 슬롯 수가 줄지 않는다.
- 서로 다른 고유 옵션은 한 카드에 함께 붙을 수 있다. 같은 종류는 중복 금지다. 철갑탄·해제·무력화 공존은 가능하지만 철갑탄 두 개는 금지다. 기본 효과에 이미 포함된 고유 효과도 중복 검사에 넣을지는 추가 확인한다.
- 같은 강도의 같은 디버프 재적용은 강도를 더하지 않고 지속시간을 갱신한다. 장갑 −1/2턴 취약이 다시 발동하면 −1인 채 다시 2턴이며 −2로 합치거나 남은 기간에2를 더하지 않는다. 서로 다른 강도는 D단계에서 각자의 기간을 보존하는 것으로 정했다. 같은 강도 재적용은 기존 남은 기간과 새 기간 중 긴 값을 유지하는 것으로 E단계에서 확정했다.

**B단계 답변:**

1. B에서는 본효과 우선으로 답했으나, 체력 소모 검토 후 E에서 **리스크 먼저→본효과**로 변경했다. 현재 규칙은 리스크 우선이다. 새 스트레스도 현재 카드의 첫 타격부터 반영하며 타격 중간에 뒤늦게 적용하지 않는다. 같은 스트레스의 강도는 합산하지 않고 유효한 가장 강한 값으로 계산한다.
2. 회복은 **카드 사용당 한 번**이다. 3회 공격+회복4가 모두 명중해도 회복은 4이며 12가 아니다. 회복4는 질문용 예시이고 실제 수치는 낮지 않게 검토하자는 사용자 의견을 기록한다. 후속 E·F에서 드로우/에너지도 카드당1회·명중 독립, 무력화는 명중한 대상당 카드1회로 정했다.
3. **플레이어 차례→적 차례를 마치면 게임 턴이 1 증가**한다. 디버프 남은 턴과 적의 행동 대기는 이 공통 게임 턴으로 감소시키는 방향이다. 진행 턴 번호는 증가하고, 남은 카운트다운은 감소한다. 정확한 감소/행동/만료의 순서는 아래 예시로 확인한다.

**C단계 확정:**

- 회복은 공격 명중과 별개의 본효과다. 공격이 전부 빗나가도 카드당 한 번 회복한다.
- 적의 대기1은 이번 적 차례에서 행동하지 않고 게임 턴 경계에 0이 된다. **다음 게임 턴의 적 차례에 행동**한다. 대기1→0이 된 차례에 즉시 실행하는 규칙은 사용하지 않는다.
- 해제는 한 번 이상 명중해야 발동한다. **첫 명중의 피해 계산 직전에 쉴드를 전량 제거**한다. 모두 빗나가면 쉴드는 유지된다.

### 공통 게임 턴과 적 행동 대기

한 게임 턴은 플레이어의 카드 행동과 적 차례를 포함한다. 카드를 여러 장 쓰는 것만으로 게임 턴이 진행되지는 않는다. 플레이어→적을 마치면 게임 턴 번호는 +1, 남은 대기·기간은 공통 게임 턴 단위로 감소한다.

| 구간 | 처리 내용 | 확정 범위 |
| --- | --- | --- |
| 플레이어 차례 | 기존 상태를 반영해 본효과 처리 → 새 리스크 적용. 준비된 적의 행동 대기를 무력화로 늘릴 수 있음 | 리스크 우선과 무력화 명중·카드당1회는 확정 |
| 적 차례 | 차례에 들어왔을 때 대기0인 적은 행동. 대기1 이상은 대기 | 대기1이 된 뒤가 아닌, 0으로 다음 차례를 맞아야 행동하는 것은 사용자 결정 |
| 게임 턴 경계 | 대기 중인 적의 남은 수와 모든 디버프 기록의 남은 기간을 한 번 감소. 새 디버프도 발동 게임 턴부터 감소. 게임 턴+1 | 디버프 첫 감소는 확정. 행동 후 새로 예약한 적 대기의 첫 감소는 구체화 |

**대기1 예시:** 게임 턴10의 플레이어 차례에 적 대기1 → 턴10 적 차례에는 행동 없음 → 경계에 대기0·게임 턴11 → 턴11 플레이어 차례에 대응 가능 → 턴11 적 차례에서 행동.

**대기5 예시:** 대기 중인 상태로 게임 턴이 진행되며 5→4→3→2→1→0, 그다음 게임 턴의 적 차례에 행동한다. 새 게임 턴의 HUD에서는 대기0을 ‘다음 적 차례에 행동’처럼 준비 완료 상태로 구분하는 안을 추천한다. 턴 종료 예상 공격 역시 이번 적 차례의 준비 상태를 기준으로 계산한다.

예고 행동은 대기 중 전역 게임 턴 번호에 맞춰 다른 행동으로 바뀌지 않게 유지하는 안을 추천한다. 적별 다음 행동과 남은 대기를 별도 기록한다. 이번 적 차례의 예상 피해에는 지금 대기0인 공격만 포함하고, 아직 대기1 이상인 공격은 포함하지 않는다.

**무력화+1 확인 예시:** 플레이어 차례에 대기0인 적에게 +1을 적용하면 이번 적 차례는 대기1이라 행동하지 않고, 경계에 0이 되어 다음 게임 턴의 적 차례에 행동한다. 실제 행동이 정확히 한 게임 턴 미뤄져야 한다. 무력화는 한 번 이상 명중한 대상에게 카드당 한 번 적용한다. 다른 카드 사용에도 다시 적용되는 즉시 대기 수치 변경이며, 적별 추가 저항/지연 상한은 아직 채택하지 않았다.

적이 행동하고 새 대기를 예약했을 때 같은 경계에서 그 새 값을 다시 줄일지, 다음 게임 턴부터 줄일지는 후속 규칙으로 명시해야 한다. 이전의 ‘대기1→0 즉시 행동’ 추천 예시는 사용자 결정에 따라 폐기했다.

### 카드 본효과 안의 명중 조건 예시

한 대상을 여러 번 공격하는 카드 기준이다. 예를 들어 피해9×3회+플레이어 회복4+해제가 있고 적 쉴드가50인 경우:

- 전부 빗나감: 회복4는 한 번 발동, 쉴드50은 유지, 공격 피해0.
- 첫 타격은 빗나가고 둘째 타격이 명중: 둘째 타격의 피해 계산 전에 쉴드50을 전량 제거. 이후 장갑/철갑탄을 반영해 피해 계산. 회복은 여전히 한 번.
- 스트레스 등 리스크를 먼저 적용해 현재 카드의 첫 타격부터 반영한다. 타격 중간에 새 리스크를 뒤늦게 넣지 않는다.

여러 대상 공격의 해제는 각 대상의 명중을 기준으로 처리하는 안을 추천하지만 적용 범위는 별도 확인한다. 드로우·에너지 획득도 카드당1회·명중 독립으로 확정되었다. 무력화는 각 명중한 대상에게 카드당1회다.

### D단계 확정과 상태 처리 예시

**승화:** 지속 중 현재 쉴드를0으로 만들고 새 쉴드 획득도 막는다. 리스크가 먼저이므로 ‘방어+12와 승화’는 승화를 먼저 적용해 본효과의 방어 획득도0이 된다. 활성 기간 중 방어 카드의 실제 쉴드 획득은0으로 예고한다. 만료되면 이후 획득이 가능해지는 것이며 기존/차단 쉴드를 따로 저장했다 복원하는 것으로 해석하지 않는다.

**서로 다른 강도의 같은 디버프:** 각 강도의 남은 기간을 따로 보존하고 동시에 감소시킨다. 겹치는 동안에는 강한 것만 적용하고 강도를 합산하지 않는다. 약한 효과는 가려져 있어도 시간이 멈추지 않는다.

| 경계 전 상태 | 이번 적 차례의 취약 | 게임 턴 종료 뒤 기록 |
| --- | --- | --- |
| 강도−3/2턴 + 강도−1/3턴 | −3 | −3/1턴, −1/2턴 |
| 강도−3/1턴 + 강도−1/2턴 | −3 | 강한 기록 만료, −1/1턴 |
| 강도−1/1턴 | −1 | 만료 |

반대로 강한 −3/3턴과 약한 −1/1턴이면 약한 기록은 가려진 상태로 먼저 만료되며 강한 효과가 끝난 뒤 다시 나타나지 않는다. 같은 강도는 기존 남은 기간과 새 기간의 최댓값으로 갱신한다. 남은3에 새1이면3 유지, 남은1에 새3이면3이다.

**디버프 첫 감소:** 발동한 게임 턴의 종료부터 기간을 감소한다. D에서 본효과 뒤 스트레스1을 마지막에 발동해 영향이 없을 수 있는 전략을 허용했으나 E에서 리스크 우선으로 바뀌었다. 따라서 **현재 카드 자신의 공격에는 새 스트레스가 적용**되고, 마지막 사용은 이후 카드/다음 턴으로 영향이 번지는 것만 피할 수 있다. 기간을 임의로 연장하지 않으며 취약1은 이번 적 차례까지 적용한 뒤 만료한다.

회복·드로우·에너지의 ‘카드당1회’는 타격수·대상수가 늘어도 반복 횟수가 늘지 않는다는 뜻이다. 각 수치는 카드 옵션에 따라 달라지며 예시 숫자를 실제 균형 수치로 확정하지 않는다. 무력화의 카드당1회는 한 카드의 여러 타격으로 같은 대상에 여러 번 지연을 주지 않는 규칙이다. 다른 카드는 별도의 사용으로 적용한다.

### 현재 카드 실행 순서의 정리

1. 사용 카드의 고유 ID와 효과를 고정하고 대상·에너지·체력 소모의 사용 가능 조건을 확인한다. 유효하지 않으면 카드/자원/침식/난수 모두 유지한다.
2. 사용 카드를 손패의 나머지 카드와 구별해 고정한 뒤 리스크와 실행 비용을 먼저 반영한다. 저주가 손패를 바꾸더라도 사용 카드를 다른 카드로 바꾸거나 두 번 소모하지 않는다.
3. 리스크를 적용한 상태로 본효과를 처리한다. 공격은 타격별 명중, 첫 명중 시 해제 후 피해 계산. 회복·드로우·에너지는 카드당1회 독립 실행. 무력화는 명중한 대상마다1회다.
4. 사용 카드의 더미 이동과 사용 침식을 한 번 정산한다. 모든 실행이 끝난 뒤 전투 종료를 판정하는 안을 추천한다. 정확한 더미 이동/저주 순서는 G에서 정의한다.

미리보기에서도 복제한 상태에 리스크를 먼저 반영해 같은 순서로 계산한다. 실제 난수와 실제 소유 상태는 변경하지 않는다. 예를 들어 기본 명중100%에 새 스트레스−20%면 현재 카드의 타격은80%이며, 승화 중 쉴드 획득은0으로 보인다. HP 부족 카드가 본효과 회복으로 나중에 비용을 충당할 수 있다고 예고하지 않는다.

### G단계 답변과 쉴드 추천안

**확정:** 쉴드12/지속2턴은 쉴드가2게임턴 동안 지속하는 의미다. 자동 리필 여부는 사용자가 아직 판단하지 않았으므로 미정으로 남긴다.

**추천:** 얻은 쉴드의 잔량을 기간 동안 보존하고 자동 리필하지 않는다. 피해 흡수로 줄어든 쉴드는 새 방어 카드를 써야 추가되며 기간0이 되면 해당 획득원의 잔량이 소멸한다.

| 시점 | 쉴드12/2턴, 리필 없음 추천안 |
| --- | --- |
| 플레이어 카드 사용 직후 | 쉴드12, 남은2턴 |
| 이번 적 차례에 피해5 흡수 | 쉴드7 |
| 현재 게임 턴 종료 | 쉴드7, 남은1턴 |
| 다음 게임 턴 시작 | 쉴드7 유지. 12로 리필하지 않음 |
| 다음 적 차례에 피해4 흡수 | 쉴드3 |
| 다음 게임 턴 종료 | 기간0으로 남은 쉴드3 소멸 |

여기서 피해5/4는 장갑 등을 거쳐 쉴드가 흡수할 실제 피해 예시다. 자동으로 매 턴12까지 리필하면 두 게임 턴 동안 총 방어량이 최대24가 되므로 효과 크기와 설명이 달라진다. 리필을 도입한다면 별도 반복 효과로 구분하는 안을 추천하며 아직 추가 기능으로 확정하지 않는다.

서로 다른 카드에서 얻은 쉴드는 디버프의 ‘최강만 적용’ 규칙을 그대로 쓰지 않는다. 획득량과 각 잔량·남은 기간을 별도 관리하는 안을 추천한다. 피해를 어느 획득원부터 차감할지(먼저 만료되는 쉴드 우선 추천)는 리필 방식 확정 후 정한다.

**저주 확정:** 사용 중인 카드는 제외하고 남은 손패를 전부 버림 더미에 보낸 뒤 같은 장수를 새로 뽑는다. 사용 카드의 고유 ID와 실행 정보를 먼저 고정한다. 카드 리스크가 먼저이므로 저주에 의한 손패 교체와 본효과 드로우가 함께 있으면 저주 교체 후 본효과 드로우를 처리하는 안으로 정리한다.

사용 카드는 진행 중인 실행으로 고정해 저주 재편 대상에서 제외하고, 실행 정산 시 버림 위치를 처리하는 안을 추천한다. 교체된 다른 카드는 ‘사용’한 것이 아니므로 사용 침식을 올리거나 저주를 다시 발동시키지 않는다. 뽑기 더미가 비어 버림을 섞는 경우도 사용 중인 원본을 중복 소모/재추첨하지 않는지 검증한다. 수동 리롤 버튼의 비용·횟수는 저주 리롤과 별도 미정이다.

**전투 종료 확정:** 플레이어에게 남은 지속 효과와 디버프는 모두 해제한다. 쉴드 잔량과 지속 버프·리스크 디버프를 다음 전투에 이월하지 않는다. 카드에 붙어 있는 리스크 옵션 자체는 유지하고 그 옵션이 전투 중 발동시킨 임시 상태만 해제한다. 불안정 표식과 침식도 소유 카드의 탐사 상태이므로 전투 종료 해제 대상에 넣지 않는다. 귀환·기지 안정화 규칙으로 따로 처리한다.

아래 처리 순서와 조합 제한 제안은 아직 확정 규칙이 아니다. 인터뷰 답변으로 갱신한다.

| 철갑탄 | 장갑만 무시 | 남은 쉴드는 별도로 피해를 흡수 |
| 해제 | 첫 명중의 피해 계산 직전에 쉴드 전량 파괴, 전부 빗나가면 미발동 | 쉴드 우회와 다르며 제거 후 다른 카드 피해에도 영향 |

리스크를 먼저 적용한 뒤 본효과에서 타격별 명중, 첫 명중 해제 → 장갑/철갑탄 → 남은 쉴드 흡수 → 체력 피해를 처리한다. 별개 회복·드로우·에너지는 명중과 무관하게 카드당 한 번이며, 무력화는 명중한 대상마다 카드당 한 번이다. 비용·회복과 다른 본효과 간 순서·사망 처리의 세부 순서는 별도로 명시한다. 드로우 결과처럼 아직 알려지지 않은 정보는 정확한 카드 이름 대신 장수와 규칙을 예고한다.

피해 9 × 3명 × 3회 × 3턴은 방어 계산 전 총 243이다. 수치 옵션과 구조 변경 옵션을 같은 가치로 추첨하면 상위 등급의 위력이 폭증한다. 초기에는 대상 확장과 다중 타격의 동시 허용을 제한하거나, 함께 붙을 때 기본 피해를 줄이는 예산을 두는 것을 추천한다. 무력화의 중첩과 보스 저항, 드로우·에너지 순환의 발동 제한도 별도로 검증한다.

주 대상 영역은 카드마다 하나를 정하는 안을 권한다. 예: ‘흡혈 사격’은 적에 놓고, 피해 후 플레이어를 자동 회복한다. 혼합 효과가 있어도 플레이어가 어디에 놓아야 하는지 유지한다. 전술 카드에 적 지정 무력화를 붙이는 등, 주 대상과 충돌하는 옵션은 호환 규칙부터 정한다.

## 7. 카드 등급·옵션 등급·리스크 선택

### 인터뷰에서 정한 방향

- 카드 고유 효과는 유지한다. 세 재료 중 결과의 기준 카드를 어떻게 고르는지는 미정이다.
- 일반 승급에서는 기존 옵션의 등급·수치를 그대로 유지하고 새 옵션만 추첨한다.
- 일반 승급의 기본 보상은 새 옵션 1개다. 선택 강화는 레어→에픽부터 가능하며, 채운 리스크 한 개에 추가 옵션 한 개를 대응시킨다. 슬롯 수용 한도와 실제 채운 수를 구분한다.
- 옵션 자체에 등급이 있으며 카드 등급을 넘는 옵션은 붙지 않는다.
- 일반 옵션은 피해·회복·방어 등의 수치 효과다. 같은 종류 중복 허용·합산 표시하되 각 옵션 기록과 슬롯은 유지한다.
- 고유 옵션은 철갑탄·해제·무력화 등의 효과다. 서로 다른 종류는 함께 보유할 수 있고, 같은 종류만 중복 금지다.
- 승급은 100% 성공한다.
- 미스틱끼리의 재합성에는 아래 일반 강화/선택 강화 규칙을 적용한다. 등급이 올라가는 일반 승급과 구분한다.

### 등급별 기본 옵션과 리스크 수용 슬롯

| 카드 등급 | 기본 후천 옵션 수 | 리스크 수용 슬롯 | 실제 채운 리스크 r | 전체 후천 옵션 수 |
| --- | ---: | ---: | --- | --- |
| 커먼/노말 | 0 | 0 | 0 | 0 |
| 레어 | 1 | 0 | 0 | 1 |
| 에픽 | 2 | 1 | 0~1 | 2+r |
| 유니크 | 3 | 2 | 0~2 | 3+r |
| 레전드리 | 4 | 3 | 0~3 | 4+r |
| 미스틱 | 5 | 4 | 0~4 | 5+r |

슬롯은 리스크를 담을 수 있는 용량이다. 비어 있으면 부작용도 추가 옵션도 없다. 일반 강화만으로 미스틱에 도달한 카드는 **기본 옵션 5개·리스크 0개·빈 리스크 슬롯 4칸**이다. 커먼→레어에서는 리스크 슬롯이 없고, 레어→에픽에서 첫 한 칸이 열린다.

기존 옵션은 일반 승급에서 등급도 수치도 다시 추첨하지 않는다. 예를 들어 레어 단계에서 붙은 피해 +4는 이후 에픽·유니크로 승급해도 레어 등급과 +4를 유지한다. 새 기본 옵션만 해당 승급 단계의 확률표를 적용한다. 이미 채운 리스크에 대응하는 추가 옵션을 다음 승급 때 다시 지급하지 않는다.

남은 경계는 **이전 등급에서 비워 둔 슬롯을 나중에 채울 수 있는지**, 그때 보너스가 **슬롯 해금 단계/현재 승급 단계 중 어느 표를 쓰는지**다. 일반 승급에서는 `기존 옵션 수 + 기본 1개 + 이번에 새로 채운 리스크 수`로 검증하는 안을 추천한다. 슬롯 용량 전체를 보너스로 다시 계산하지 않는다. 미스틱의 역순 추첨 규칙을 다른 등급에 자동 확대하지 않는다.

### 미스틱 일반 강화와 선택 강화

미스틱 재합성에서는 **기존 옵션·리스크를 교체**한다. 기존 리스크가 3개인 카드에서 이번 리스크를 1개로 선택하면 **총 옵션 6개·리스크 1개·빈 슬롯 3칸**으로 재구성한다. 기존 부작용이나 추가 옵션을 새 결과에 덧붙이지 않는다.

- 일반 강화: 기본 옵션 5개 재추첨, 리스크 0개, 빈 리스크 슬롯 4칸.
- 선택 강화: 리스크 r개(0~4)를 선택, 기본 5개+추가 r개, 실제 리스크 r개, 빈 슬롯 4−r개.

| 선택 리스크 r | 기본 옵션 수 | 추가 슬롯이 사용하는 승급 단계 확률표 | 결과 전체 옵션 수 | 실제 리스크 / 빈 슬롯 |
| ---: | ---: | --- | ---: | --- |
| 0 | 5 | 없음 | 5 | 0 / 4 |
| 1 | 5 | 미스틱 | 6 | 1 / 3 |
| 2 | 5 | 미스틱·레전드리 | 7 | 2 / 2 |
| 3 | 5 | 미스틱·레전드리·유니크 | 8 | 3 / 1 |
| 4 | 5 | 미스틱·레전드리·유니크·에픽 | 9 | 4 / 0 |

리스크0으로 재합성하면 기존 부작용만 없어지는 것이 아니라 그 대가인 기존 보너스 옵션도 함께 교체되고 기본 5개로 돌아간다. 미스틱 세 장을 재료로 쓰는 비용은 유지된다. 합성의 코어 기준 카드와 침식 승계는 별도 미정이다.

### 기본 5개가 사용하는 확률표

| 기본 슬롯 | 성장 단계 | 적용하는 옵션 등급 확률표 |
| --- | --- | --- |
| 1 | 커먼/노말 → 레어 | 레어 단계 표 |
| 2 | 레어 → 에픽 | 에픽 단계 표 |
| 3 | 에픽 → 유니크 | 유니크 단계 표 |
| 4 | 유니크 → 레전드리 | 레전드리 단계 표 |
| 5 | 레전드리 → 미스틱 | 미스틱 단계 표 |

기존 옵션의 실제 등급을 유지한 채 종류·수치만 바꾸는 방식이 아니라 **해당 승급 단계의 확률표로 옵션 등급부터 다시 추첨**한다. 추가 r개는 최상위 단계부터 역순으로 배정한다. 예를 들어 r=3이면 기본 5개 외에 미스틱·레전드리·유니크 표를 각각 한 번 더 쓴다.

이는 **추첨표 단계**이며 결과 옵션의 등급 보장이 아니다. 미스틱 단계 표에 레전드리/미스틱 옵션이 섞여 있다면 그 비율로 추첨한다. r=3에서는 기본 슬롯과 추가 슬롯에 미스틱 표가 하나씩 있지만, 미스틱 등급 옵션 2개가 보장되는 것은 아니다. 단계별 실제 확률은 아직 미정이다.

기본 효과와 후천 옵션은 별도로 관리한다. 슬롯에는 기본/보너스 구분과 추첨 단계, 실제 결과 옵션의 등급·수치를 기록한다. 재합성에서는 기존 옵션 목록에 5+r개를 더하지 않고 정해진 결과 슬롯을 구성한다. 세 재료의 옵션 수를 합산하거나, 재합성 때마다 옵션 수를 +1하지 않는다.

### 리스크와 옵션 구성의 검증

- 일반 옵션의 표시 합산은 슬롯 수를 바꾸지 않는다. 기본 5개와 추가 r개 전체에 걸쳐 고유 옵션 중복·호환 규칙을 적용한다. 보너스 슬롯이라는 이유로 철갑탄 등이 중복되지 않게 한다.
- 일반 승급은 기존 옵션 기록을 보존한다. 미스틱 재합성은 정해진 슬롯을 재추첨하는 별도 처리다.
- 확률표 선택, 옵션 등급, 옵션 종류, 수치 추첨을 구분한다. 미스틱 카드라도 레어 단계 슬롯을 무조건 미스틱 풀로 바꾸지 않는다.
- 리스크 자체의 종류·강도와 그 대가인 보너스 슬롯을 함께 기록한다. 일반 승급의 기존 부분 보존과 미스틱 재합성의 전체 교체를 구분해 검증한다. 미스틱 3리스크→1리스크이면 옵션 6개/리스크 1개가 되며, 그 상태에서 다시 일반 재합성하면 옵션 5개/리스크 0개다.
- 수치 리스크인 파멸의식은 침식에 적용한다. 불안정 카드도 누적 침식이 귀환 후 남는다. 귀환 시 리스크 자체가 제거되는지는 별도 미정이다.
- 생성 단계부터 적용 경로가 없는 리스크는 제외하는 안을 추천한다. 다른 옵션이나 플레이로 부작용을 완화하는 전략까지 금지하는 뜻은 아니다.
- 옵션이 늘어도 손패에는 합산 요약을 표시한다. 피해 +3과 +5는 피해 +8로 표시하고 상세에서 각 옵션의 등급·수치를 확인하는 안이다. 리스크 역시 주요 결과와 개수 위주로 요약한다.

### 제시된 리스크의 규칙표 — 수치는 미정

| 리스크 | 사용자가 제시한 효과 | 먼저 정할 것과 HUD 예고 |
| --- | --- | --- |
| 에너지 소모 증가 | 해당 카드의 에너지 비용 증가 | 기본 비용과 가산량, 실제 최종 비용, 에너지 부족 시 사용 불가 |
| 체력 소모 | 사용 시 체력 지불 | 비용 지불 시점, 체력이 부족할 때 사용 허용 여부, 체력 변화 |
| 취약 | 장갑 수치 감소 | 임시 수치/방어구 레벨 구분, 최저 0 여부, 지속·중첩. 다음 적 공격의 체력 피해 재계산 |
| 스트레스 | 플레이어 공격 명중률 감소 | 강도·최저 명중률을 정함. 새 스트레스는 현재 카드 본효과 전에 적용, 명중은 타격별 판정·예고 |
| 승화 | 지속 중 현재 쉴드0 및 새 쉴드 획득 차단 | 본효과 전에 발동해 해당 카드의 쉴드 획득도0이 되며, 만료 뒤 과거 쉴드를 복원하지 않음 |
| 저주 | 사용 중인 카드를 제외한 남은 손패 전부 버림→동장수 뽑기 | 사용 카드 고정·버림 재섞기·리롤 재귀 방지. 강제 패 순환의 균형 검증 |
| 파멸의식 | 수치 증가 효과는 새 명칭의 침식 증가로 표현 | 자신/손패/덱 중 범위, 고정 %p/누적 배율, 귀환 정산과 관계 |

같은 디버프의 강도는 합산하지 않는다. 다른 강도는 각각의 기간을 보존하고 강한 것만 적용한다. 가려진 기록도 함께 감소한다. 같은 강도는 기존 남은 기간과 새 기간 중 긴 값을 유지한다. 리스크에는 강도·남은 기간·출처가 필요하다. 취약은 임시 장갑 수치와 영구 방어구 레벨을 구분하는 안을 추천한다. 새 리스크는 카드 본효과 전에 발동하고, 디버프 기간은 발동한 게임 턴 종료부터 한 번씩 줄어든다. 적은 대기0이 된 다음 게임 턴의 적 차례에 행동한다.

명중은 타격마다 개별 판정하고 각 타격의 명중률을 예고한다. 스트레스로 명중률이 생기면 ‘예상 피해’를 확정처럼 예고하지 않는다. **명중률 / 적중 시 피해 / 처치 가능성**을 구분한다. 예를 들어 방어가 없는 체력 18인 적에게 피해 9×3회, 각 타격의 명중률 80%가 일정하다면 2회 이상 명중할 확률은 89.6%다. 이는 각 타격을 개별 판정하는 확정 방향의 예시다. 미리보기에서는 난수를 소비하거나 결과를 먼저 뽑지 않는다.

저주의 손패 교체는 카드 사용이 아니므로 다시 저주를 발동시키거나 교환된 카드에 사용 침식을 올리지 않는 안을 추천한다. 리스크 우선 순서에 맞춰 사용 카드 ID를 고정한 뒤 저주와 나머지 손패를 처리하고, 교체 후 같은 손패 인덱스의 다른 카드를 잘못 소모하지 않게 한다. 수동 리롤과 강제 리롤은 공통 교체 로직을 쓰되 비용·발동 원인을 구분한다. 명중 결과·소모·침식 누적·카드 이동은 한 실행으로 저장하며, 사망 손실은 별도 이벤트로 한 번만 정산한다.

## 8. 승급 확률과 옵션 추첨 확률

**확정: 등급 승급은 100% 성공.** 기존 초안의 승급 실패·재료 반환·누적 보정 질문은 종료한다. 재료를 쓰는 별도 수치 강화까지 실패가 없는지는 아직 확정하지 않았다.

상위 등급 직접 획득이 없고 모두 노말부터 합성한다면, 확정된 6등급의 레어·에픽·유니크·레전드리·미스틱 1장 원가는 각각 노말 **3·9·27·81·243장**이다. 미스틱 3장 재합성은 노말 729장 환산이다. 실제 획득 속도는 드롭·상점·퀘스트에 따라 달라진다.

| 추첨 단계 | 결정 / 추천 / 미정 |
| --- | --- |
| 승급 성공 | 사용자 확정: 100% |
| 카드 고유 효과 | 사용자 확정: 유지. 세 카드 중 어느 카드를 기준으로 삼는지는 미정 |
| 옵션 추가 개수 | 사용자 확정: 기본 1개 + 선택한 리스크 수만큼 추가 |
| 새 옵션 등급 | 카드 등급 이하. 등급별 추첨률은 미정 |

| 별도 재료 강화 | 성공률·비용·결과·최대 수준은 추후 인터뷰 |

### 새 옵션 등급 추첨의 비교안 — 아직 미채택

카드의 새 등급을 g라고 할 때 두 후보를 비교할 수 있다.

- 후보 A: g−2 / g−1 / g 등급을 20 / 50 / 30%로 추첨한다. 최저 등급 아래의 몫은 최저 등급에 합친다. 결과 편차가 크다.
- 후보 B: g−1 / g 등급을 50 / 50%로 추첨한다. 옵션의 최소 등급이 분명하고 승급에 따른 단계적 성장을 확인하기 쉽다.

후보 B를 6등급에 적용하면 레어는 노말/레어, 에픽은 레어/에픽, 유니크는 에픽/유니크, 레전드리는 유니크/레전드리, 미스틱은 레전드리/미스틱 옵션을 각각 50%로 추첨한다. 이는 아직 채택하지 않은 실험값이며, 고유 옵션별 최소 해금 등급과 수치 범위도 정해야 한다.

초기 검증에는 B를 추천하지만 아직 채택하지 않았다. 카드 등급 g에서 g+1 옵션은 확률 0%다. 미스틱 선택 강화의 보너스는 사용자 결정에 따라 최상위부터 역순의 단계 표를 적용하며, 그 표의 확률을 임의로 더 높이지 않는다. 옵션 종류와 수치의 실제 가중치는 따로 정해야 한다.

추첨은 ‘카드 등급 이하 → 역할 호환 → 고유 중복/조합 제한’으로 가능한 후보를 확인한 뒤 진행한다. 고유 옵션을 이미 보유해 특정 등급의 후보가 없으면, 가능한 등급의 확률을 다시 정규화하고 실제 적용 확률을 공개한다. 추첨 실패를 이유로 합성만 성공하고 옵션을 지급하지 않는 결과는 허용하지 않는다. 추가 옵션 2개를 뽑을 때도 첫 번째 결과를 반영해 두 번째 후보를 다시 계산한다. 미스틱 전체 재추첨에서는 교체되어 사라질 기존 옵션을 중복 검사에 남겨 두지 않는다. 보존할 코어·옵션과 이번에 새로 뽑은 옵션을 기준으로 검사하며, 코어 고유 효과와 후천 고유 옵션의 중복 금지 범위는 먼저 정의한다.

일반 승급은 기존 옵션을 자동 상향하지 않는다. 같은 출발 카드가 각 등급에 도달했을 때 보존된 기존 옵션과 새 옵션을 나누어 비교한다. 미스틱 재합성도 같은 개수를 다시 뽑는다는 이유만으로 기존보다 강해진다고 보장하지 않는다. 옵션 등급·종류·수치의 확률과 유지하는 리스크를 함께 평가한다.

고정 난수로 추첨 결과를 재현하고, 일반 승급의 기존 옵션 등급·수치 보존, 신규 옵션 개수·등급 상한·고유 중복·금지 조합·리스크 연결을 검증한다. 미스틱은 기본 5개와 선택 5+r개 수량, 각 슬롯의 단계 표, 고유 중복 제한, 합의한 리스크 정산이 반복 합성에도 유지되는지 검증한다. 분포 검증은 확률 구현을 검증하며 실제 재미와 균형은 별도 플레이로 확인한다.

## 9. 기지와 탐사 상점의 재사용 범위

상점 화면·상품 상세·매매 확인·퀘스트 목록은 공통으로 구성할 수 있다. 반면 기지 창고 접근, 상인별 재고, 탐사 중 결제 통화, 판매대금의 귀환 전 보존 여부는 맥락별 규칙으로 둔다. 판매대금도 귀환 전 탐사 전리품으로 유지하는 안을 추천한다. 탐사 상인을 통해 즉시 안전한 기지 자산으로 전환할 수 있게 할지는 인터뷰에서 결정한다.

퀘스트도 탐사 중 처치 기록, 귀환해서 제출하는 재료, 보상 수령을 구분한다. 아이템 제출과 보상 지급은 함께 저장하며 중복 수령을 막는다. 창고 확장 보상은 60칸 기본 용량에 더하는 확장치로 기록한다.

## 10. 인터뷰 진행 상태

### 답변 반영 완료

1. 불안정 표식과 사용 누적 수치를 분리했다. ‘침식’은 추천 가칭이다. 불안정은 귀환 제거, 침식은 귀환 일부 감소·기지 추가 완화다.
2. 고유 효과 유지, 옵션 등급과 카드 등급 상한, 일반/고유 옵션을 정했다. 일반 승급에서는 기존 옵션 등급·수치를 유지하고 새 옵션만 추첨한다.
3. 승급 실패 없음, 기본 옵션 1개와 리스크 1개당 추가 옵션 1개 원칙을 정했다.
4. 선택 강화는 레어→에픽부터 가능하다. 리스크 수용 슬롯은 에픽1/유니크2/레전드리3/미스틱4이며 비워둘 수 있다.
5. 미스틱 재합성은 기존 옵션·리스크 교체. 일반은 옵션5/리스크0, 선택은 옵션5+r/리스크r다. 보너스는 미스틱부터 역순 단계 표를 쓴다.
6. 리스크는 비용·체력 소모와 취약·스트레스·승화·저주·파멸의식 등이며 사용 시 발동해 정해진 턴 지속한다. 명중은 타격별 판정/예고다.
7. 커먼/노말→레어→에픽→유니크→레전드리→미스틱 6등급이다.
8. **배낭의 모든 카드는 획득 즉시 전투 덱에 편입**된다. 별도의 장착 덱 선택을 요구하지 않는다.
9. 효과 A단계: 일반 옵션 중복 합산·개별 기록 유지, 다른 고유 옵션 공존/같은 종류 중복 금지, 동일 디버프 강도 비합산/기간 갱신이다.
10. 효과 B·C단계: 리스크 먼저/본효과 나중, 회복은 카드당1회이며 공격 명중과 별개로 발동한다. 해제는 첫 명중의 피해 계산 전에 쉴드를 전량 제거한다. 플레이어→적을 마치면 게임 턴+1, 적 대기와 디버프 기간은 공통 게임 턴 단위를 쓴다. 적 대기1은 현재 경계에0, 다음 게임 턴 적 차례 행동이다. 새 디버프는 발동 게임 턴 종료부터 기간을 감소한다.
11. 효과 D단계: 승화는 지속 중 쉴드0/획득 차단, 다른 강도는 각자 기간을 보존하며 강한 효과만 적용, 새 디버프도 현재 게임 턴 종료부터 감소한다. 스트레스1 마지막 사용 전략은 현재 카드의 불이익은 받되 이후 전이만 피하는 것으로 E의 순서 변경을 반영한다.
12. 효과 E·F단계: 처리 순서를 리스크 우선으로 변경했다. HP 소모량 이하이면 사용 불가, 드로우·에너지도 명중 독립/카드1회, 무력화는 명중한 대상에 카드1회, 같은 강도 기간은 최댓값 유지다.
13. 효과 G단계: 저주는 사용 카드 제외 남은 손패 모두 버림/같은 장수 뽑기, 전투 끝 플레이어 지속/디버프 모두 해제다. 쉴드12/2턴은 지속 기간 의미이며 자동 리필은 아직 미정, 잔량 유지가 추천안이다.

### 남아 있는 질문과 검토

- 앞서 전달한 등급별 침식 누적 방향과 새 옵션 등급 확률은 아직 미정이다.
- 효과 A~G 답변을 반영했다. 쉴드 자동 리필/잔량 유지와 쉴드 획득원별 소모 순서가 남아 있다. 저주와 수동 리롤의 범위를 혼동하지 않는다.

### 첫 구현의 완료 기준

- 같은 카드 한 장이 배낭·창고에 동시에 존재하지 않으며, 전투의 더미는 배낭 카드 ID를 참조한다.

- 미스틱 3리스크→1리스크는 옵션6/리스크1/빈 슬롯3, 이후 일반 재합성은 옵션5/리스크0/빈 슬롯4가 된다.

## 12. 기존 게임 적용과 군사 분위기 전환 검토

사용자 추가 희망: 확정한 시스템을 기존 게임에 적용하는 비용을 검토하고, 게임 배경을 타르코프를 연상시키는 분위기로 바꾸고 싶다는 요청. 이 단계는 적용 범위·방향 검토이며 실제 코드/아트/배포는 변경하지 않았다.

- 재사용: 고정 시점2.5D 렌더링, 모바일 입력, 카드 선택/드래그, HUD/상세 패널, 전투→보상→귀환 흐름.
- 구조 변경: 카드 개별 소유와 저장 이관, 배낭 카드 전체의 즉시 덱 편입, 공통 효과 계산, 실행별 명중/사망 결과 저장.
- 원화 작업: 배경·적·무기·소품의 재질과 명암을 맞출수록 작업량이 늘어난다. 렌더러 변경만으로 사실적인 재질이 생기지는 않는다.

추천 적용 순서는 (1) 카드/저장 모델과 확정 효과 이식, (2) 대표 전투 한 구역과 하단 HUD의 완성, (3) 인벤토리·창고와 탐사 정산, (4) 기지 시설·상점·퀘스트·합성 확장이다. 첫 검증 구역은 낡은 군수 창고 또는 검문소 한 곳을 추천한다. 전체 시설을 한 번에 포함하는 범위로 확대하지 않는다.

아트 추천은 기존 고정 시점2.5D를 유지하며 현대 군사·폐쇄 산업 구역을 표현하는 것이다. 콘크리트 회색·철제 표면·올리브 군용 장비·비상등, 먼지와 생활 흔적, 엄폐물·상자·철문·배관으로 깊이를 구성한다. 배경이 어두워져도 적 실루엣과 카드/HUD 한글은 읽히도록 대비를 유지한다. 이는 스타일 제안이며 타르코프 원본 화면을 이번 작업에서 관찰/분석했다고 주장하지 않는다.

승화·저주·파멸의식 등 기존 명칭을 전술적으로 해석할지, 비정상 카드 기술이 섞인 세계관으로 유지할지는 미정이다. 이번 배경 희망을 이유로 효과나 명칭을 임의로 변경하지 않는다.

정확한 토큰 수·요금은 사전에 확정할 수 없다. 전체 기능 이식은 작업량이 큰 편이며 특히 효과 조합 검증·저장 이관·신규 아트 제작이 비중을 차지한다. 확정 문서를 기준으로 필요한 파일만 검토하고 작은 단위로 구현·검증해 반복 작업을 줄이는 방식을 추천한다. 이미지 생성 도구의 과금 조건은 확인하지 않았으므로 금액을 추정하지 않는다.

## 13. 첫 적용 단계 — 2026-10-25

사용자의 ‘차근차근 웹 게임에 적용하자’에 따라 문서 검토에서 첫 구현으로 진행했다. 앞 장의 ‘코드는 변경하지 않았다’는 각 인터뷰 당시의 상태다.

이번 단계에 연결한 범위는 카드별 UID와 v2 저장 이관, 공통 전투 실행/확률 미리보기, 적의 대기0 행동 규칙, 리스크 우선·독립 효과·개별 타격·해제/철갑탄/무력화·디버프 기간 처리다. 기존 전투→보상→귀환 흐름에 연결했고 배낭의 모든 UID가 전투 덱을 이룬다. 발견 카드는 불안정으로 추가되고 귀환하면 개별 안정 카드로 보존된다. 중복 종류도 사라지지 않는다.

플레이어 HUD를 좌측 하단, 배낭을 우측 하단에 배치하고 턴 종료·리롤을 손패 근처에 둔다. 공격은 적, 방어/회복은 플레이어 HUD, 전술은 배낭에 드롭하며 미리보기 후 릴리즈로 한 번 사용한다. 배낭은 좌측 조회 오버레이를 연다. 군수 창고 환경의 콘크리트·올리브·철문·창문 빛·비상등·배관을 적용하며 고정 시점 2.5D를 유지한다.

### 플레이 테스트용 임시 기준

- 쉴드는 잔량 유지·자동 리필 없음. 먼저 만료되는 획득원부터 소모하며 각 게임 턴 종료에 기간 감소. 사용자가 자동 리필을 확정한 것은 아니므로 추후 비교 대상이다.
- 수동 리롤은 에너지1·게임 턴당1회, 전 손패 버림/같은 장수 드로우. 카드 사용이 아니므로 저주·침식을 재발동하지 않는다. 폐기 카드는 일반 재섞기에 포함된다.
- 발견 카드는 뽑기 더미에 추가하고 섞는다. 이번 프로토타입은 전투 사이 보상에서 획득하므로 다음 구역 시작에도 배낭 전체를 섞는다.
- 신규 예시 카드의 수치와 리스크는 전투 조합을 시험하기 위한 프리셋이며 최종 옵션 확률표나 승급 결과가 아니다.

### 다음 단계와 경계

60칸 창고와 물건 이동, 실제 개별 카드 출정 선택, 건설·상점·퀘스트, 3장 승급/미스틱 재합성은 미구현이다. 기존 추가 장착2종 선택은 유지하며, 배낭에 들어온 이후에는 별도 활성 덱을 요구하지 않는다. 침식 데이터는 불안정 표식과 분리해 저장하지만 등급별 누적률·귀환 감소량·확률 손실과 안정화 경제는 미정이므로 작동 수치를 임의로 확정하지 않는다.

진행 중 탐사 저장/재개는 아직 연결하지 않았다. 새로고침은 기지 준비로 돌아가고 확정된 귀환 저장은 유지된다. 전투 종료 시 플레이어 지속 효과/쉴드만 제거하며 카드 고유 리스크와 소유 데이터는 유지한다. v1 저장 원본을 삭제하지 않고 이전 v2 백업을 남긴다.


## 14. 화면 구성 검토 후 최신 결정

이 장은 팀장 UI 구성안에 대한 사용자 피드백과 정비 인터뷰 답변을 반영한다. 화면/규칙 설계 단계이며 이번 갱신에서 게임 코드는 변경하지 않았다.

### 확정한 방향

- 배낭은 현재 구조를 유지한다. 소지한 모든 카드가 전투 덱에 포함되며 손패/뽑기/버림 더미는 배낭의 카드 UID를 참조한다. 팀장안의 한 장 다시 뽑기를 채택했다고 해석하지 않는다.
- 장비는 카드 운용을 보조한다. 구체적인 무기/방어구 보정 효과는 후속 설계한다.
- 적도 카드 시스템을 사용한다. 난이도를 조절하기 위해 적의 행동 규칙에 제한을 둔다. 제한의 구체적인 덱 크기/행동 횟수/대기/사용 횟수 수치는 아직 확정하지 않았다.
- 탐사에 소지한 장비·아이템·재료·돈은 사망 시 모두 잃는다. 기지 창고는 탐사 소지품과 분리한다.
- 카드 손실은 우선 안정 카드 보존·불안정 카드 소멸로 채택한다. 불안정 표식은 귀환 시 제거한다. 안정 카드의 사용 누적 수치에 따른 사망 확률 소멸은 보류한다.

### 정비 단계

전투 승리 후 현재 보상 카드를 고르는 단계에서 확장한다. 승리한 적이 소지했던 아이템·장비·재료·돈을 회수할 수 있다. 회수 가능 목록과 배낭 용량을 구분하며, 적의 모든 물품이 회수 후보라는 것이 배낭에 무조건 전부 들어간다는 뜻은 아니다.

- 정비에는 사용할 수 있는 정비 턴이 주어진다. 최초 지급량은 미정이다.
- 아이템 이동/정리에 1턴을 소모하며, 그 이동 작업 안에서는 아이템 이동 횟수를 제한하지 않는다. 드래그 한 번마다 1턴으로 해석하지 않는다. 여러 이동을 미리 편집하고 ‘이동 확정’으로 지불하는 UI는 추천안이다.
- 소지한 카드 한 장을 사용하는 데 정비 턴 1을 소모한다. 카드에 붙은 리스크도 정비 중 적용한다. 기존의 리스크 우선·본효과 나중과 체력 소모 후 생존 조건은 공통 규칙으로 연결한다.
- 정비 턴이 0이 되면 정비를 종료하고 다음 지역으로 이동할 맵 선택 화면으로 넘어간다. 시간 초과로 추가 정비를 계속하거나 적이 즉시 재등장하는 규칙을 임의로 넣지 않는다.
- 정비 행동 선택 → 실행 가능 여부 확인 → 행동 확정/효과 처리 → 정비 턴 소모 → 남은 턴이 0이면 맵 선택 순서로 구성하는 안을 추천한다. 미리보기·취소·실행 불가 행동은 소모하지 않도록 설계한다.

### 구현 전에 남은 경계

- 정비 턴 지급량, 조기 정비 종료 허용, 맵 선택의 귀환/최종 지역 연결.
- 카드 기본 에너지 비용도 정비 턴과 함께 지불하는지, 정비의 에너지 공급 방식. 사용자는 리스크 적용을 확인했으며 기본 에너지 비용 면제/유지는 아직 확정하지 않았다.
- 정비에서 사용할 수 있는 카드 범위와 선택 원천(남은 손패/배낭), 적 사망 후 공격 대상 처리, 드로우·저주 등 전투 더미 효과의 의미.
- 정비 중 발동한 지속 리스크의 기간 감소 및 다음 전투 이월. 기존 ‘전투 종료 시 해제’를 정비 중 새로 발동한 효과에 그대로 확장해 즉시 삭제하지 않는다.
- 기존 승리 보상 카드 선택과 적 전리품 회수를 함께 제공할지, 카드 선택/장비 착용/돈 회수 등이 이동 작업의 1턴에 포함되는지.
- 정비 종료 후 미회수 전리품의 처리와 재방문 가능 여부.

14장 기획 정리 당시의 프로토타입은 손패 전체 리롤(에너지1·턴당1회)이었다. 이후 변경은 15장을 따른다. 기지/창고·장비 실물·적 카드 덱·정비 턴/맵 선택은 구현 예정이며 현재 화면에 이미 적용된 기능으로 안내하지 않는다.


## 15. 손패/리롤 및 카드 표현 피드백 적용 — 2026-10-25

사용자의 최신 답변을 기준으로 기존 ‘턴 종료 시 전 손패 버림’과 ‘에너지1·턴당1회 즉시 교체’를 교체한다.

- 턴 종료: 남은 손패 UID와 순서를 보존한다. 적 행동 후 에너지3, 손패 기본5장까지 빈자리를 뽑기 더미에서 보충한다. 추가 드로우로 손패가5장을 넘은 경우 그대로 유지하며 상한은8이다.
- 사용한 카드는 버림 더미로 이동한다. 일반 턴 보충/드로우에서는 버림 더미를 자동으로 회수하지 않는다. 남은 뽑기 카드가 부족하면 가능한 장수만 보충한다.
- 수동 리롤: 남은 손패·뽑기·버림 카드를 합쳐 섞고 손패와 버림 더미를 초기화한다. 앞서 요청한 턴 소모를 반영하여 적 행동 후 새 손패5장을 뽑는다. 별도 에너지1 비용은 제거한다. 에너지0/빈 손패에서도 가능하며 적 행동 중에는 중복 실행할 수 없다.
- 저주는 기존의 카드 사용 중 즉시 교체 규칙을 유지한다. 사용 중인 카드는 재활용에서 제외하고 필요하면 버림 카드를 섞어 같은 장수를 뽑는다. 저주를 수동 리롤의 턴 종료로 연결하지 않는다.
- 카드 테두리: 노말 회색, 레어 녹색, 에픽 파랑, 유니크 보라, 레전드리 노랑, 미스틱 빨강. 금속 그라데이션과 등급 이름으로 구별한다.
- 카드 본문: 합산 효과를 짧은 파란색 볼드로 표시하고 다음 줄에 리스크 이름/수치/기간을 표시한다.
- 상세 툴팁: 실제 저장 카드의 템플릿 기본값과 추가 옵션을 분리하여 기본(+추가)로 보여준다. 기본이0인 추가 드로우/에너지도0(+1)로 표시한다. 하단에 각 강화 옵션의 등급/수치와 리스크 설명을 배치한다. 정상적인 미리보기/설명 확인은 수치·난수·카드 소유 상태를 변경하지 않는다.
- 예시 ‘응급 처치: 회복12+21, 에너지0+1, 드로우0+1, 승화3턴’은 표시 및 테스트 사례이며 기본 응급 처치 카드의 능력치나 보상을 임의로 바꾸지 않는다.
