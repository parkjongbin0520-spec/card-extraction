# Cardkov 밀리터리 도트 에셋 팩

[에셋 갤러리](../assets.html?v=10) · [도트 에셋 팩 다운로드](../assets/cardkov-art-pack.zip?v=10)

큰 형태와 제한된 색으로 군용 장비를 읽을 수 있게 만든 Escape from Cardkov 전용 아트입니다. 타르코프의 군사·생존 분위기는 실용적인 군장, 낡은 산업 시설, 올리브·회색·황갈색, 차가운 빛과 작은 주황 작업등으로 전달합니다.

## 공통 아트 기준

| 요소 | 배포용 원본 크기 | 표현 규칙 |
| --- | --- | --- |
| 메뉴·기지·전투 배경 | 480×270 | 문·기둥·배관·상자를 큰 덩어리로 구성, 낮은 대비 |
| 적 | 48×72 | 성인 군인 비례, 개체당 8~12색, 대표 특징 세 가지 |
| 장비·아이템 | 32×32 | 대표 실루엣을 중심으로 종류 구분 |
| 카드 일러스트 | 96×64 | 행동을 나타내는 중심 소재 하나 |
| 소품 플레이트 | 48×72 셀 | 바닥 접점을 공유하는 상자·기둥·단말 |
| 1인칭 무기 | 160×125 | 총과 장갑 낀 손을 큰 명암 덩어리로 표현 |
| 플레이어 초상 | 32×32 | 얼굴과 군장의 대표 형태 |
| UI | SVG | 각진 모서리, 3단계 금속 색 띠, 정수 좌표의 형태 |

월드 이미지는 공통 24색 팔레트를 사용합니다. 재질마다 그림자·기본색·밝은 면의 세 단계를 기본으로 하며, 작은 봉제선·나사·잔흠집과 상시 노이즈는 생략합니다. 경계병은 두건·얇은 재킷·긴 소총, 중장갑병은 헬멧·넓은 방탄복·두꺼운 어깨로 구분합니다. 적의 머리·상체·무기가 배경보다 먼저 읽히도록 대비를 조정합니다.

한글·숫자·툴팁은 선명한 일반 글자를 유지합니다. 카드의 효과는 파란색 볼드, 상세 추가 수치는 주황색입니다. 여섯 등급은 노말 강철색·레어 녹색·에픽 파랑·유니크 보라·레전드리 노랑·미스틱 빨강과 등급 이름으로 표시합니다. 프레임의 금속빛은 연속적인 광택 대신 세 단계 색 띠와 작은 하이라이트로 표현합니다. UI의 정보 색은 월드용 24색 제한과 분리합니다.

## 제작과 파일 형식

기존의 사실적 이미지를 모자이크 처리하는 대신, 특징 중심의 도트 아트로 새 배경·캐릭터·장비·카드 원화를 `imagegen`으로 제작했습니다. 생성 원화는 정해진 픽셀 크기와 공통 팔레트로 내보내며, 배포에는 **네이티브 픽셀 크기의 무손실 PNG**를 사용합니다. 투명한 플레이트의 가장자리도 픽셀 경계에 맞춥니다. 프레임·표면·아이콘은 프로젝트에서 작성한 SVG입니다. 다른 게임에서 추출한 이미지·로고·텍스처는 포함하지 않습니다.

이미지는 정적 파일로 제공됩니다. 실행 중 이미지 생성 API, 외부 이미지 서비스 또는 추가 설치가 필요하지 않습니다. PNG는 아틀라스를 포함해 38개이며, UI는 SVG 15개입니다. 아이콘 스프라이트 한 파일에 상태·자원·행동 아이콘 20종이 들어 있습니다. ZIP에는 현재 도트 PNG·SVG, 갤러리·스타일·경로 도우미와 이 문서를 포함합니다. 이전 사실적 WebP 팩은 새 ZIP에 포함하지 않습니다.

## 고정 시점 2.5D와 가독성

배경과 캐릭터·소품은 분리된 이미지입니다. 낮은 해상도의 공통 전투 캔버스에 바닥 그림자와 깊이 순서에 따라 합성한 뒤 픽셀 경계를 유지하며 확대합니다. 부드러운 보간, 미세한 스케일 변화와 연속적인 광택을 줄여 서로 다른 밀도의 그림이 섞이는 것을 방지합니다. 이미지 크기가 바뀌어도 적의 선택·드래그 판정은 화면의 실제 위치에 맞춰 유지합니다.

아틀라스의 순서는 경계병, 중장갑병, 드론, 상자, 기둥, 단말입니다. 발 기준은 48×72 셀의 69px입니다. 로딩 실패 시 기존 벡터 플레이트·절차형 공간으로 복구합니다. 기존 `assets/generated/`의 사실적 WebP는 이전 버전 자료로 남아 있지만 현재 도트 갤러리와 다운로드 팩에서는 사용하지 않습니다.

카드 설명이나 화면 크기에 따라 일러스트를 줄이거나 숨겨 수치와 리스크를 우선합니다. 이미지에는 같은 이름의 설명을 중복하지 않으며 인접한 제목과 수치가 정보를 전달합니다. 모바일 세로·가로에서 적과 배경의 구분, 장비 식별, 카드 가독성과 드래그 미리보기·릴리즈 사용을 확인합니다. 게임 규칙과 저장 형식은 변경하지 않습니다.

`assets/ui/field-icons.svg`에는 체력·장갑·에너지·쉴드, 디버프, 카드 상태·옵션, 자금, 배낭·창고·강화소, 리롤·드로우·귀환 아이콘이 들어 있습니다. [UI 에셋 안내](../assets/ui/README.md?v=10)에서 호출 방법을 확인할 수 있습니다.
