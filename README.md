# DEAD HAND — 카드 익스트랙션

둠 분위기의 2.5D 공간에서 진행하는 **고정 시점 턴제 카드 게임**입니다. 적·소품·손·총기는 직접 제작한 2D SVG 플레이트이며, 바닥·벽과 원근·그림자를 공유합니다. 전투 중 자유 이동은 없고 카드와 대상 선택으로 행동합니다.

**플레이:** https://parkjongbin0520-spec.github.io/card-extraction/

## 실행

계정·앱 설치·패키지 설치가 필요 없습니다. 정적 웹 페이지로 배포하며, 외부 라이브러리·웹 폰트·이미지 서버·API에 의존하지 않습니다. 페이지의 로컬 리소스가 로드된 뒤에는 네트워크 연결 없이 전투할 수 있습니다.

개발용 서버는 저장소 루트에서 다음과 같이 실행합니다.

```sh
python3 -m http.server 8000
```

## 플레이 흐름

1. **진입 경로 선택:** 돌파는 높은 전리품, 보급 우회는 약한 적과 승리 시 체력 8 회복을 제공합니다. 보급 경로의 기본 CR 보상은 돌파의 65%입니다.
2. **고정 시점 전투:** 모든 적과 다음 행동이 공개됩니다. 적과 카드를 선택하고, 예상 효과·비용을 확인한 뒤 **사용** 버튼으로 확정합니다. 모든 카드에 동일한 확인 절차를 적용합니다.
3. **턴 종료:** 살아 있는 적이 예고한 행동을 실행합니다. 이후 손패 5장과 에너지 3을 보충합니다.
4. **보상 카드 선택:** 구역을 확보하면 CR와 카드 한 장을 얻습니다. 보상 선택 후 회수 판단 창이 바로 열립니다.
5. **철수 또는 진입:** 귀환하면 CR와 발견한 희귀 카드가 확정됩니다. 계속 진입하면 체력과 미확정 전리품을 유지한 채 다음 경로를 선택합니다.

실패하면 이번 탐사의 전리품과 카드를 잃습니다. 기본 덱 12장과 이전 귀환 기록은 보존됩니다. 희귀 카드는 준비 화면의 보관함에서 최대 2장까지 추가 장착합니다. CR는 이번 버전에서 회수 성과를 기록하는 점수이며 구매 기능은 없습니다.

## 전투 규칙

- **공격:** 표시한 피해를 턴 종료 시 줍니다. 적을 먼저 제압하면 그 적의 행동은 취소됩니다.
- **방어:** 적은 방어 6을 얻습니다. 다음 플레이어 턴의 공격 피해를 흡수하며, 소모될 때까지 유지됩니다.
- **조준:** 이번 턴에는 공격하지 않습니다. 다음 턴의 공격 의도를 확인할 수 있습니다.
- 플레이어 방어는 이번 적 턴의 피해를 흡수하고 턴 종료 후 사라집니다.
- 적의 장갑은 공격마다 피해를 줄입니다. 철갑탄은 장갑과 방어를 무시합니다.
- 수류탄은 화면의 살아 있는 모든 적에게 피해를 줍니다.
- 손패 상한은 8장입니다. 새 턴에는 남은 손패를 버립니다. 뽑기 더미가 비면 버린 카드를 섞어 다시 사용합니다.
- 적 행동 처리 중에는 카드·대상·턴 종료 조작을 잠급니다. 가이드나 보관함을 열면 적 행동의 결과 처리는 닫을 때까지 대기합니다.

| 조작 | 동작 |
| --- | --- |
| 카드 클릭·터치 / 1–8 | 카드 선택 및 효과 미리보기. 선택만으로 소모되지 않음 |
| 적 클릭·터치 | 대상 선택. 카드를 사용하거나 에너지를 소모하지 않음 |
| 사용 버튼 / F / Enter | 선택한 카드의 효과 확정. 공격은 현재 대상에게 적용 |
| ← → | 대상 변경 |
| 턴 종료 버튼 / Space | 적 행동 후 다음 플레이어 턴 |
| E | 확보한 구역에서 회수 판단 창 열기 |
| Esc | 가이드 열기 / 일반 창 닫기 |

휴대폰은 손패를 좌우로 밀어서 확인합니다. 세로·가로 레이아웃과 노치·홈 표시줄 안전 영역을 지원합니다. 이동 패드·자유 조준·미니맵은 고정 시점 전투 전환에 맞춰 제거했습니다.

## 정보는 필요할 때 확인

- 기본 화면에는 **내 체력·에너지, 턴, 턴 종료 예상 피해**와 적의 **체력·행동 아이콘**을 표시합니다.
- 손패에는 **비용·이름·핵심 효과**만 표시합니다. 반복되는 설명·최대 체력·장갑·턴 규칙은 기본 화면에서 접습니다.
- PC는 **마우스 올리기**, 키보드는 **Tab 포커스**, 모바일은 **약 0.4초 길게 누르기**로 상세 정보를 확인합니다. 길게 누르기는 카드 선택이나 사용을 실행하지 않습니다.
- 카드를 선택하면 손패 영역의 상세 패널에 **현재 대상에 대한 실제 효과**를 표시합니다. 사용 버튼과 전장을 가리지 않으며, 사용 버튼을 눌러야 자원이 소모됩니다.
- 에너지가 부족한 카드도 설명을 확인할 수 있습니다. 사용 버튼은 비활성화됩니다.
- 적을 살펴보면 이름·최대 체력·장갑·방어·다음 행동과 선택 카드의 피해를 확인할 수 있습니다.
- 체력·방어·에너지·예상 피해 아이콘도 클릭·포커스·길게 누르기로 설명을 엽니다. 덱 아이콘에서 뽑기/버림 목록을 확인합니다.
- 상세 창은 X·Escape·바깥 누르기로 닫습니다. 도움말·보상·경로 창을 열 때도 닫힙니다.
- 전투 피드백은 잠깐 표시한 뒤 사라집니다. 메뉴를 제외한 상시 텍스트를 줄이고, 상세 설명의 읽기 쉬운 글자 크기는 유지합니다.

## 아트와 파일

- `scene.js`: 고정 카메라, 원근 공간, 공통 광원으로 미리 처리한 플레이트, 가장자리·방향성 그림자, 대기·공격·피격 연출
- `assets/field-plates.svg`: 경계병·장갑병·드론·상자·기둥·단말의 원본 SVG 아틀라스
- `assets/weapon-plate.svg`: 손과 총기 전경 플레이트
- `game.js`: 경로·카드·적 의도·턴·보상·저장·입력·맥락별 설명 데이터
- `inspect.js`: 마우스·키보드·터치가 공유하는 단일 상세 패널
- `index.html`, `style.css`, `battle.css`, `context.css`: 모바일 화면과 카드 트레이·대상 UI
- `docs/art-direction-2.5d.md`: 아트 방향과 고정 시점 전환의 적용 기준

적의 발·그림자를 공통 바닥에 맞추고, 중경 소품과 적은 깊이 순서로 합성합니다. 원본 SVG에서 광원·얇은 가장자리·실루엣 그림자용 이미지를 한 번 준비해 재사용합니다. 지상 적은 발을 기준으로 작게 움직이고 드론은 부유합니다. 동작 줄이기 설정에서는 반복 움직임과 시차를 끕니다. 카드에는 별도의 평면 HTML 텍스트를 사용해 한글 가독성을 유지합니다. 모바일은 30fps를 목표로 렌더링하며, 단말별 실측 성능은 다를 수 있습니다. 다른 게임의 이미지나 원본 에셋은 포함하지 않았습니다.

브라우저 `localStorage`의 기존 `deadhand-save-v1` 보관함을 이어서 사용합니다. 같은 브라우저·사이트 주소에서 저장이 유지됩니다. 저장소가 차단되면 현재 창에서만 보존됩니다.

## GitHub Pages

배포용 `gh-pages` 브랜치의 루트에서 게시합니다. `index.html`뿐 아니라 `scene.js`, `game.js`, `inspect.js`, 세 CSS 파일과 `assets/`를 함께 배포해야 합니다. `.nojekyll`을 포함합니다.

처음 활성화할 때는 [Pages 설정](https://github.com/parkjongbin0520-spec/card-extraction/settings/pages)에서 **Deploy from a branch → gh-pages → /(root) → Save**를 선택합니다. 이후 `gh-pages` 브랜치에 푸시하면 자동 배포됩니다.
