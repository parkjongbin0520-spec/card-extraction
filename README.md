# Escape from Cardkov

[웹에서 플레이](https://parkjongbin0520-spec.github.io/card-extraction/) · PC·모바일 브라우저에서 다운로드·가입 없이 실행하는 카드 익스트랙션 게임입니다.

카드가 주 전투 수단입니다. 장비는 카드 운용을 보조하고, 전리품과 정비 시간이 탐사의 위험을 만듭니다. 고정 시점의 2.5D 산업 공간에서 적이 예고한 카드를 보고 행동합니다.

## 플레이 흐름

**메인메뉴 → 기지에서 출정 준비 → 진입 경로 → 전투 → 상자방 → 정비 → 지역 맵 → 다음 지역 / 상인 / 귀환 → 생존·사망 결과 → 기지**

메인메뉴는 탐사 시작·기지·환경 설정·종료 안내를 제공합니다. 기지와 메뉴에는 직접 제작한 별도 SVG 배경을 사용하고, 설정 배경은 메뉴 장면을 흐리게 표현합니다. 웹의 종료 버튼은 기록을 저장하고 브라우저 탭을 닫는 방법을 안내합니다.

## 기지와 소유품

- **배낭:** 모든 소지 카드가 즉시 전투 덱에 포함됩니다. 카드·아이템이 공간을 공유합니다. 장착한 장비는 별도 슬롯입니다.
- **창고:** 기본 60칸. 배낭과 함께 열리며, ⠿ 드래그 또는 선택 후 이동 버튼으로 양방향 이동합니다. 모두 창고로 보내기·정렬을 제공합니다. 공간이 부족하면 가능한 것만 옮기고 나머지를 보존합니다.
- **장비:** 주무기1·주무기2·방어구·배낭. 주무기는 공격 카드의 피해를, 보조무기는 명중을 보조합니다. 방어구는 장갑을, 배낭은 소지 한도를 결정합니다.
- **통화:** 보관 자금과 휴대금을 분리합니다. 기지에서 휴대금을 보관하거나 50 CR씩 가져갈 수 있습니다.
- **건설:** 상점·강화소를 무료 건설합니다. 테스트 단계에서는 건설 재료를 요구하지 않습니다.
- **상점:** 카드·장비·재료·소모품 구매/판매와 상인 의뢰를 제공합니다. 구매는 창고에 입고합니다.
- **의뢰:** 생환·적 제압·재료 납품. 수락·완료·보상은 저장되며 중복 보상을 막습니다. 생환 의뢰는 창고를 12칸 확장합니다.
- **능력 강화:** 금속 부품과 보관 자금으로 최대 체력·기본 장갑·창고를 강화합니다.
- **대여 덱:** 재출정 수단으로 기본 카드 12장 한 세트를 추가로 받을 수 있습니다. 대여 카드는 판매·합성할 수 없고 중복 수령할 수 없습니다.

## 카드 성장과 표시

노말→레어→에픽→유니크→레전드리→미스틱 6등급입니다. 회색·녹색·파랑·보라·노랑·빨강의 금속 그라데이션 테두리와 등급 이름으로 구분합니다.

합성에서는 같은 등급의 안정 카드 3장을 선택합니다. 첫 카드가 기준이며 고유 효과를 유지하고 다른 2장을 소모합니다. 승급은 실패하지 않습니다. 기존 옵션의 등급·수치는 보존하고 새 옵션 1개를 뽑습니다. 레어→에픽부터 리스크를 선택해 리스크 1개당 옵션을 1개 더 얻습니다. 리스크 용량은 에픽1/유니크2/레전드리3/미스틱4입니다.

미스틱 재합성은 기존 옵션·리스크를 교체하여 기본5개+선택r개, 리스크r개로 재구성합니다. 기본 옵션은 레어부터 미스틱까지 각 단계의 확률표를, 보너스는 미스틱부터 역순 단계의 표를 사용합니다. 실제 확률은 강화 화면에서 펼쳐볼 수 있으며 **현재 표는 테스트용**입니다.

카드 본문은 파란색 합산 효과와 다음 줄의 짧은 리스크로 압축합니다. 마우스 호버·Tab 포커스·모바일 길게 누르기로 `기본(+추가)` 수치, 각 강화 옵션의 등급·수치, 리스크 설명을 봅니다. 배낭/창고의 카드도 상세 설명을 제공합니다.

## 전투와 정비

공격은 적, 방어·회복은 좌측 하단 플레이어 HUD, 전술은 우측 배낭에 끌어 놓습니다. 유효 대상이 강조되고 주변은 어두워집니다. 미리보기는 자원·난수를 소모하지 않으며 대상 위에서 릴리즈하면 한 번 사용합니다. 모바일 카드의 ⠿ 손잡이는 드래그, 본문 가로 밀기는 손패 스크롤입니다. 같은 카드를 다시 누르면 선택을 해제합니다.

리스크→본효과 순서입니다. 체력 소모 후 1 이상 남아야 하며, 같은 카드의 회복·에너지로 비용을 미리 충당할 수 없습니다. 타격마다 명중을 판정하고 회복·드로우·에너지는 명중과 별개로 카드당 한 번 처리합니다. 철갑탄은 장갑만 무시하고 해제는 첫 명중 전에 쉴드를 전량 제거합니다. 무력화는 명중한 대상의 대기를 카드당 한 번 늘립니다. 대상 수 옵션은 선택한 적을 우선합니다.

적은 작은 고정 카드 덱에서 **대기 종료 시 예고한 카드 한 장만** 같은 효과 계산기로 사용합니다. 추가 드로우·에너지로 연속 사용하지 않습니다. 대기0은 이번 적 차례, 대기1은 이번 게임 턴 종료에0이 되어 다음 적 차례에 행동합니다. 양측이 사용한 카드 이름과 장비 정보를 표시합니다.

시작 손패5장·상한8장. 턴 종료는 남은 손패를 보존하고 적 행동 후 에너지3·5장까지 빈자리만 보충합니다. 일반 보충은 버림 카드를 회수하지 않습니다. 리롤은 남은 손패·뽑기·버림을 합쳐 섞고 턴을 넘긴 뒤 새 손패5장을 뽑습니다. 별도 에너지 비용은 없습니다. 저주는 사용 중인 카드를 제외한 즉시 손패 교체이며 수동 리롤과 다릅니다.

전투 승리 후 상자를 열면 **정비3턴**이 주어집니다. 적의 무기·방어구·재료·돈과 보상 카드1장을 회수할 수 있습니다. 여러 물건의 이동을 자유롭게 편집하고 **확정에1턴**을 씁니다. 취소·미리보기·실행 불가에는 소모하지 않습니다. 카드 사용에는 정비1턴과 기본 에너지·리스크를 함께 적용합니다. 장비 교체·구급 키트·지연 수류탄 사용도 각각1턴입니다. 0턴이면 지역 맵으로 이동하며, 조기 종료도 가능합니다. 남겨둔 전리품은 회수하지 않습니다.

전투 종료 시 기존 지속 효과를 해제합니다. 정비에서 새로 얻은 효과는 정비 행동마다 기간이 줄고 남은 기간을 다음 전투에 이월합니다. 정비 중 드로우와 소지 카드 더미도 유지됩니다. 지연 수류탄은 다음 전투에서 카운트다운 후 같은 피해 계산으로 폭발합니다.

## 정산과 저장

귀환 시 불안정 카드를 안정화하고 소지품·휴대금을 배낭에 보존합니다. 자동으로 창고나 보관 자금에 넣지 않습니다. 사망하면 소지 장비·아이템·재료·돈과 불안정 카드가 소멸하고 **안정 카드와 기지 창고는 보존**됩니다. 자발적으로 판매·합성한 카드는 정산 후 복구되지 않습니다.

카드별 UID와 v2 저장은 유지하며 기지 정보와 행동 단위의 탐사 기록을 추가했습니다. 이전 v1 원본과 v2 이전 저장 백업을 보존합니다. 새로고침 후 메뉴의 ‘진행 중 탐사 계속’으로 재개합니다. 이미 정산한 명중·전리품·합성 결과를 다시 추첨하지 않습니다. 로고 또는 Escape에서 일시 정지·메뉴 복귀·탐사 포기를 선택할 수 있습니다.

**테스트 설정:** 정비3턴, 기본/장착 배낭16/24/32칸, 쉴드 잔량 유지·자동 리필 없음, 정비 중 기본 에너지 지불, 장비/아이템 사용1턴, 가격·강화 비용·옵션 확률/수치 등은 초기 비교를 위한 임시 설정입니다. 안정 카드의 침식 확률 소멸은 사용자 결정으로 보류했습니다. 등급별 사용 침식·귀환 감소·안정화 경제는 연결하지 않았으며 신규 합성 리스크 추첨에서도 침식을 제외합니다. 에픽 추가 후 별 문양은 미확정이므로 등급 이름·색상을 사용합니다.

## 개발과 검증

런타임 의존성이 없는 정적 사이트입니다. `python3 -m http.server 8000` 후 `http://localhost:8000`을 엽니다.

- `node --test tests/*.test.cjs`: 전투·소유·저장·합성·경제·사망 정산 단위 검사
- Playwright/Chromium이 있는 개발 환경: `GAME_URL=http://localhost:8000 node tests/browser-feedback.cjs`
- 전체 흐름: `GAME_URL=http://localhost:8000 node tests/browser-campaign.cjs`
- 모바일 창고 드래그·일시 정지/재개: `GAME_URL=http://localhost:8000 node tests/browser-mobile.cjs`

`campaign.js`는 기지/소유/합성/거래, `screens.js`는 메인메뉴/기지/설정, `combat.js`는 공통 카드 효과, `game.js`는 탐사·정비·저장 흐름을 담당합니다. `scene.js`와 자체 SVG는 고정 2.5D 공간, `drag.js`/`inspect.js`는 입력과 상세 설명을 담당합니다. GitHub Pages는 `gh-pages` 루트에서 게시합니다.
