# DEAD HAND — 카드 익스트랙션 프로토타입

[웹에서 플레이](https://parkjongbin0520-spec.github.io/card-extraction/) · 다운로드나 가입 없이 PC·모바일 브라우저에서 실행합니다.

카드가 주 전투 수단이고 탐사·귀환이 보상을 결정합니다. 고정 시점의 2.5D 공간에서 적의 의도와 대기 턴을 보고 카드를 사용합니다. 자유 이동이나 실시간 조준은 없습니다.

## 이번 단계: 전투 규칙과 소유 데이터

- 카드마다 고유 ID를 부여합니다. 배낭·손패·뽑기·버림 더미가 같은 ID를 참조하고, 같은 종류의 회수 카드도 각각 보존합니다.
- 기존 CR·귀환 횟수·카드 해금·추가 장착을 `deadhand-save-v2`로 이관합니다. v1 원본과 백업을 보존하며, 손상된 v2는 백업 복구 또는 현재 창에서만 진행합니다.
- 배낭의 모든 카드가 전투 덱입니다. 보상 카드는 불안정 상태로 배낭과 뽑기 더미에 들어가며, 다음 구역에서도 사용할 수 있습니다. 귀환하면 불안정 표식이 제거되고 사망하면 이번 발견 카드는 소멸합니다.
- 리스크를 먼저 지불하고 본효과를 처리합니다. HP 소모 후 1 이상 남아야 하며 같은 카드의 회복·에너지로 비용을 미리 충당할 수 없습니다.
- 타격별 명중을 판정합니다. 회복·드로우·에너지 획득은 명중과 별개로 카드당 한 번, 무력화는 명중한 대상마다 한 번입니다.
- 철갑탄은 장갑만 무시하고 쉴드는 흡수합니다. 해제는 첫 명중 피해 전에 쉴드를 전량 제거합니다.
- 취약·스트레스·승화·저주를 지원합니다. 같은 강도는 남은 기간 최댓값을 유지하고, 다른 강도는 각 기간을 보존하며 최강 효과만 적용합니다. 전투 종료 시 지속 효과를 해제합니다.
- 적 대기 0은 이번 적 차례에 행동합니다. 대기 1은 이번 게임 턴 종료에 0이 되고 다음 게임 턴 적 차례에 행동합니다. 플레이어→적이 끝나면 게임 턴이 증가하고 새 디버프도 남은 기간이 감소합니다.
- 제압 사격·차폐 파쇄·긴급 수혈·장기 엄폐가 보상에 등장하여 다중 타격·무력화·해제·승화·저주·지속 쉴드를 시험할 수 있습니다.

## 조작과 화면

카드를 한 번 누르면 선택하고 같은 카드를 다시 누르면 해제합니다. 선택 후 사용 버튼 또는 드래그로 확정합니다. 공격은 적, 방어·회복은 좌측 하단 내 상태, 전술은 우측 하단 배낭으로 끕니다. 유효 대상은 강조되고 주변은 어두워집니다. 대상 위에서 손을 떼면 한 번 사용하고, 바깥에 놓으면 취소됩니다. 모바일에서는 카드의 ⠿ 손잡이로 끌고 카드 본문을 가로로 밀어 손패를 스크롤합니다.

드래그 미리보기는 피해·체력 범위·타격별 명중률·처치 확률을 표시하며 자원과 난수를 소비하지 않습니다. PC 마우스 올리기, Tab 포커스, 모바일 길게 누르기로 상세 설명을 봅니다. 배낭 버튼은 좌측 인벤토리 조회창을 엽니다. 전투 중 조회는 게임 턴을 진행하지 않습니다.

키보드: `1–8` 카드 선택, `← →` 대상, `F / Enter` 사용, `Space` 턴 종료. 내 턴에는 시간 제한이 없습니다.

초기 테스트 설정: 에너지 3, 새 턴 손패 5장, 상한 8장. 수동 리롤은 에너지 1·게임 턴당 1회이며 카드 사용 리스크를 발동하지 않습니다. 저주는 사용 중인 카드를 제외한 손패를 버린 뒤 같은 장수 뽑습니다. 뽑기 더미가 비면 버림 더미를 섞으므로 기존 카드가 다시 나올 수 있습니다.

**임시 조정 기준:** 쉴드는 자동 리필 없이 잔량을 유지하며 먼저 만료되는 획득원부터 소모합니다. 리롤 비용·횟수와 보상 카드 수치는 플레이 테스트용입니다. 옵션 추첨 확률·등급별 침식 증가·귀환 감소·기지 안정화 비용은 아직 정하지 않아 적용하지 않았습니다.

## 아트와 다음 단계

낡은 군수 창고의 콘크리트·올리브 도장·녹슨 철문·배관·찬 창문 빛·주황 비상등을 적용했습니다. 고정 카메라, 바닥에 맞춘 평면 캐릭터와 소품, 깊이 순서 합성·그림자·피격 연출을 유지합니다. 기존 자체 SVG 플레이트를 재사용한 첫 환경 작업이며 다른 게임의 원본 에셋은 포함하지 않습니다. 모바일은 30fps를 목표로 하고 동작 줄이기 설정을 반영합니다.

이번 버전은 전투와 저장 기반을 먼저 적용했습니다. 기존 추가 장착 2종 UI는 유지합니다. **60칸 창고·배낭 간 이동·건설·상점·퀘스트·3장 승급·미스틱 재합성**은 다음 단계입니다. 탐사 도중 새로고침하면 작전 준비로 돌아가며 진행 중 탐사는 저장하지 않습니다. 안정 카드의 침식 확률 손실은 수치와 정산 규칙 확정 후 연결합니다.

전체 합의와 미정 항목: [기획 및 구현 순서](docs/systems-roadmap-and-interview.md), [2.5D 아트 방향](docs/art-direction-2.5d.md).

## 개발과 검증

설치할 의존성이 없는 정적 사이트입니다. 로컬에서 `python3 -m http.server 8000` 후 `http://localhost:8000`을 엽니다. 규칙 및 저장 검증은 `node --test tests/*.test.cjs`로 실행합니다.

- `combat.js`: DOM과 분리된 전투 실행·확률 미리보기·게임 턴 계산
- `card-model.js`: 카드 인스턴스·옵션 정규화·저장 이관·백업
- `game.js`: 탐사 흐름·보상·더미·HUD·입력 연결
- `scene.js`, `assets/`: 고정 시점 2.5D 산업 공간과 자체 SVG 플레이트
- `drag.js`, `inspect.js`: 대상별 드래그·취소·확정과 맥락별 상세 패널
- `index.html`, 세 CSS 파일: 반응형 화면

GitHub Pages는 `gh-pages` 브랜치 루트에서 게시합니다. 위 파일과 `assets/`, `.nojekyll`을 함께 배포합니다.
