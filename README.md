# DEAD HAND — 카드 익스트랙션

FPS 시점의 탐사와 턴제 카드 전투를 결합한 싱글플레이 웹 프로토타입입니다. 카드가 사격·방어·회복 행동을 결정하며, 구역마다 전리품을 확보해 귀환하거나 더 위험한 구역으로 진입할 수 있습니다.

## 실행

**`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.** 빌드, 패키지 설치, 계정, 게임 다운로드가 필요하지 않습니다. 그래픽과 사운드를 코드로 생성하며 외부 라이브러리, 웹 폰트, 이미지, API를 요청하지 않습니다. 인터넷 연결 없이도 동작합니다.

개발용 HTTP 서버가 필요하면 저장소 루트에서 다음 명령을 실행합니다. Python은 개발 서버를 위한 선택 사항이며 플레이에 필요하지 않습니다.

```sh
python3 -m http.server 8000
```

브라우저에서 서버의 8000번 포트를 엽니다. 정적 호스팅에는 `index.html`, `style.css`, `game.js` 세 파일을 함께 배포하면 됩니다.

## 플레이

| 조작 | 동작 |
| --- | --- |
| WASD / ↑ ↓ | 전진·후진·좌우 이동 |
| ← → / 화면 드래그 | 좌우 시점 회전 |
| 카드 클릭 / 1–8 | 카드 선택. 방어·회복·전술 카드는 즉시 사용 |
| 적 클릭 / 조준 후 F | 선택한 공격 카드로 사격 |
| Space / 턴 종료 버튼 | 적 공격 → 새 손패 5장·에너지 3 보충 |
| E / 단말 접속 버튼 | 근처 회수 단말에서 귀환·다음 구역 선택 |
| Esc | 가이드 열기 / 일반 창 닫기 |

모바일에서는 왼쪽 아래 방향 버튼을 누른 채 다른 손으로 화면을 드래그해 이동·조준할 수 있습니다. 공격 카드를 고른 뒤 오른쪽 **사격** 버튼을 누르거나 적을 직접 터치하세요. 손패는 좌우로 밀어서 확인하고 **턴 종료** 버튼으로 진행합니다. 세로·가로 화면 모두 지원하며, 가로 화면에서는 카드가 화면 오른쪽에 배치됩니다.

- 적은 감지되거나 공격받으면 활성화되며 **플레이어의 턴 종료 후에만 공격**합니다. 활성화된 적의 공격은 이동으로 취소되지 않습니다.
- 방어는 이번 적 턴에만 유효합니다. 장갑은 각 공격의 피해를 줄이며, 철갑탄은 장갑을 무시합니다.
- 뽑기 더미가 비면 버린 카드를 섞습니다. 손패 상한은 8장입니다.
- 적을 모두 제압하면 보상 카드 1장을 고릅니다. 북쪽 녹색 단말로 이동해 귀환하거나 다음 구역에 진입합니다.
- 귀환하면 CR와 발견한 희귀 카드가 보관함에 저장됩니다. 실패하면 이번 탐사의 전리품만 잃습니다.
- 회수한 희귀 카드는 작전 준비 화면의 보관함에서 최대 2장까지 장착할 수 있습니다. 기본 덱 12장은 유지됩니다.

## 구현 범위

- 레이캐스팅 기반 1인칭 공간, 충돌, 조준, 사격 연출, 미니맵
- 3개 구역, 8종 카드, 경계병·장갑병·드론, 공격 의도 표시
- 덱 순환, 에너지, 방어, 회복, 광역 피해, 장갑 무시
- 구역 보상, 중간 철수, 다음 구역 진입, 승리·패배·재출정
- 브라우저 `localStorage` 기반 보관함·추가 장착 저장
- 선택형 합성 사운드, 전체 화면, 한국어 가이드, 멀티터치 이동·조준과 큰 사격 버튼
- 작은 휴대폰·태블릿과 가로 화면 대응, 노치·홈 표시줄 안전 영역, 모바일 30fps 렌더링

저장은 같은 브라우저와 같은 사이트 주소에서 유지됩니다. 파일 직접 열기의 저장 정책은 브라우저마다 다르며, 저장소가 차단되면 현재 창에서만 진행 기록을 유지합니다. CR는 이번 프로토타입에서 회수 성과를 기록하는 점수이며 구매 기능은 없습니다.

## 파일

- `index.html`: 게임 화면과 접근 가능한 조작 UI
- `style.css`: 화면 구성과 반응형 스타일
- `game.js`: 게임 규칙, 입력, 저장, Canvas 렌더링, 합성 사운드

현재 버전은 카드 전투와 철수 판단을 검증하기 위한 프로토타입입니다. 적의 공격은 턴제로 처리되며, 일반 FPS의 실시간 사격이나 멀티플레이는 포함하지 않습니다.

## GitHub Pages

배포용 `gh-pages` 브랜치의 루트에 정적 파일과 `.nojekyll`을 둡니다. 처음 활성화할 때는 [Pages 설정](https://github.com/parkjongbin0520-spec/card-extraction/settings/pages)에서 **Deploy from a branch → gh-pages → /(root) → Save**를 선택합니다. 이후 `gh-pages` 브랜치에 푸시하면 자동 배포됩니다.

Pages 활성화 및 배포가 완료되면 접속 주소는 https://parkjongbin0520-spec.github.io/card-extraction/ 입니다. 휴대폰에서 이 주소를 열면 계정이나 앱 설치 없이 플레이할 수 있습니다.
